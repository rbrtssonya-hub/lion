# Live2D Runtime Dependencies

These files are vendored for local-first loading by the homepage:

- `pixi.min.js`: PixiJS 7.4.2, https://github.com/pixijs/pixijs
- `pixi-live2d-display-cubism4.min.js`: pixi-live2d-display 0.4.0, https://github.com/guansss/pixi-live2d-display
- `live2dcubismcore.min.js`: Live2D Cubism Core for Web 5.3, https://www.live2d.com/en/sdk/download/web/

Keep the corresponding upstream licenses and Live2D SDK terms in force when distributing the finished work.
