# ADR-003 · standard 工程记忆

## 背景与授权

用户显式调用 wiki-memory 技能并要求标准工程记忆，供后续深入开发恢复工程上下文。本轮开始时没有既有项目 AGENTS 或记忆体系。

## 已采用选择

- 用户指定 standard。Agent采用 `docs/wiki_memory/`，与开发文档集中，避免根目录混入创作资源和另一份记忆入口。
- 按指定 Skill 的 `memory.py` 先预览后应用，建立五页当前状态、入口、协议、日志MOC、配置与独立维护工具，根 `AGENTS.md` 接入。
- 视频入口、三维场景、章节内容、素材制作和验证有不同维护节奏，架构、约束、当前待办与问题分开。选择依据记录于入口手写区域；不以普通 src/tests/docs 目录数量作为复杂度判断。
- 使用工具版本 `2.1.0`，事实根据源码/配置更新；用户选择与 Agent常规实现选择注明决策来源。未执行验证和未完成功能保持明确，日志记录历史，状态页保存当前事实。

## 代价与范围

后续每轮至少读取概览、约束与待办，受影响模块再读相关页面；有持久价值的开发结果需同步。工具仅做结构体检，不能保证事实正确或代替浏览器测试。记忆需随仓库跟踪或迁移后才可跨机器恢复。

## 实施与验证线索

standard 初始化已完成，本轮五页事实、ADR和知识按迁移源码填写。最后统一 `index --apply` 与 `check`；命令见记忆协议。个人 Skill 更新不自动覆盖项目内工具和协议，不重新运行 init 覆盖已有体系。

## 后续替代

本页保留2026-10-09初始化时的选择与理由。用户随后明确要求记忆直接位于工程根目录，取消独立入口文件，改由README统一导航；现行布局与导航由 [[决策/ADR-004-根目录记忆与README导航.md|ADR-004]] 替代。standard模式保持有效，原初始化路径不再是当前使用位置。
