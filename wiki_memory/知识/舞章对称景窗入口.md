# 舞章对称景窗入口

## 当前入口与路由

用户于 2026-10-29 授权按山水参考图实施。`#/action` 为舞章选择页，`#/theater` 为原四面巨幕厅，`#/state` 为八态纵深；后两者顶栏父章均映射到“舞”。展厅与八态提供“返回舞章入口”，主导航“舞”打开选择页。

## 视觉与交互

原背景字节保存在 `source/public/assets/dance-entrance/paper-landscape.png`。两处景窗等宽，初始左右 `+13°/-13°` 镜像；左窗用动作海报与四段视频海报呈现暖金环幕，右窗用已有八态图构成宣纸纵深画廊。入口是原生 CSS3D 分层预览，不同时加载完整展厅和八态场景。

`usePortalView` 仅维护入口局部变量，水平环看 ±19°、俯仰 ±7°；鼠标拖动、方向键、Home 和归位按钮均可用。6px 阈值区分点击与拖拽；window 释放/取消、失焦及 buttons=0 兜底防止陈旧拖拽。卸载清理全部监听与动画帧，减少动态时保留显式操作。静态图由原站 AI 辅助素材复用，页面注明预览性质。

## 助手与参考来源

入口用独立知识语境 `dance`，原展厅继续使用 `action` 及原固定录音。`page-action` 来源点击映射到 `theater`，避免返回选择页；入口不进入五段固定音频的 `chapterGuides`，动态语音合成/试听本轮未验收。

Mostar 参考版本 `302800b7ec50fa243e2dae155e3ba6a2b2b9b2f6`，核实时无许可证声明。借鉴分层、缓动和指针交互思想，独立改写 React 代码；未复制其源码或媒体。详细来源、取舍和验证边界见 [来源记录](../../source/references/dance-entrance-2026-10-29.md)。
