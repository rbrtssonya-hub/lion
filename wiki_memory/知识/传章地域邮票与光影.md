# 传章地域邮票与光影

## 当前来源和范围

runGo.cmd启动的是炫技3的editions/regional，不能误用根src旧八态版。当前导入基线8764e9b有12张地域邮票、52参数、六算法；运行代码复用现工程Three0.160，没有升级全站Three或新增第二入口。双版本源码和完整根记忆作为历史资料归档到source/archives/xuanji3/original-project；运行只部署12张地域PNG，旧八态版不挂载。

SpreadPage保留当前三级Blender视频地图及设置，清空旧右栏标题、实景照片、图注、前后翻图与说明排版，改为四枚对应邮票。hongkong/kualalumpur/sanfrancisco通过placeId对齐原地图的连字符ID。右票聚焦更新左图选中；左侧改选另一城市时关闭旧票聚焦，切组取消旧区域状态。四票按实际可用容器排成2×2，种子随机角度不会随React重绘抖动，完整图片等比且聚焦大于原票。

## 最新透明呈现选择

用户在首版实览后明确取消右侧浅色矩形底板。宿主CSS、加载与静态回退均透明；WebGL启用alpha并清为0，DappledLight的transparentBackground宿主选项跳过staticPaper全屏底色输出。原背景shader及参数仍保留供来源/JSON兼容，当前页面不绘制这层底色。聚焦也无暗色底；保留票面纸边、光斑、法线和柔和投影。设置中两个独立底色控件不参与当前呈现，禁用并就近说明；其值仍属于原52字段的导入导出合同。这是用户追加要求，不是漏迁移shader。

## 光影管线和生命周期

services/spread-stamps包含完整artwork、motion、SurfaceTexture、NCS色彩、StampMaterial、DappledLight、GLSL和Gallery适配。原8个GLSL模板逐字相同：RGB光场→50tap离屏模糊→票面48tap虚化/微法线→六种合成→24tap柔影；原staticPaper输出模板保留但透明模式不绘制。阴影和票面用真实透明像素合成，不用CSS伪造光场。

首次真正GPU绘制成功后报告ready；指针与键盘限于右区域，隐藏页暂停、跨章卸载释放renderer、纹理、法线引用、事件、RO和RAF。画布丢失或首次WebGL不可用时显示完整静态邮票并允许原位重试；静态票仍可聚焦及返回。底层实现动态加载，不阻塞首页引入全部Three渲染代码。只读host.getStampDiagnostics返回实际GPU uniforms、绘制次数和光场pass统计，不能用它替代像素验证。

## 设置合同

新一级页签“邮票”管理完整52字段、六预设、组与全部重置、原v1/v2参数JSON及全站设置导入、粘贴、复制、独立/全站导出。持久键前缀stamp，resolveSpreadStampParameters恢复原字段形态；保留.479等源精度。沿用现有即时预览、显式保存、取消确认和保存基线；传章邮票设置开放实际悬停/聚焦测试，保存继续，取消退出。原面板聚焦/返回按钮由正式React回调接到当前地图邮票，不模拟DOM点击。

“章节→传章”仅管理原地图视频设置和实际使用的邮票区域宽度，旧底板材质控件移除；公共材质应用范围也排除这一透明区域，章节与视频为4处、全部内容为10处。旧spreadOverlay字段仍保留默认值、归一化和JSON兼容，不能因读取历史设置而恢复背景。小醒进入传章或电脑窗口改变时按当前控件边界寻找空位并留8px间距；不持续干预手动拖拽位置。

## 历史与验证入口

源仓库10次提交与当前主线无共同祖先，最大blob6,262,000字节，可保留原SHA和merge拓扑作为集成第二父，不需要上次炫技5的大文件兼容改写。1283份跟踪文件逐项复制校验，未跟踪prompt和Picture_01按源工程约定保全但不纳入；外部源目录不修改。

验证入口为npm test/npm run build、新spread-stamps与spread-stamp-settings生产专项，以及更新后的地图/传章原回归。必须证明真实GPU六算法、纸纹/投影/光场、透明像素、三组联动、事务保存/取消和生命周期；历史截图、源码hash、模板等同或测试配置存在都不能代替当前实际运行。具体结果见本轮功能日志。
