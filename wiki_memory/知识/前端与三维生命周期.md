# 前端与三维生命周期

适用融合首页、文化长页、全局导航/设置与结构模型模块。2026-10-19本轮复核并更新模型替换、部件选择、双栏构图及资源生命周期；其余章节的历史验证保留原日期，不作为本轮通过证据。独立intro/structure页面和视频结束转模型已被替代；当前探索更多滚到首页史册。自2026-10-14起开发与验收仅以电脑端为目标，正式回归结果由对应交付日志记录。

## 路由与页面

Hash现行路由为 `#/entry`、`#/model`、`#/action`、`#/state`，导航名称为首页、结构、动作、神态；“结构”替代旧名“狮头与结构”，不改变model路由，顶部仍不显示章节数字。旧 `intro`→`entry`、`structure`→`model`，初始化和hashchange时用 `replaceState` 规范别名，不新增历史记录；空、非法和旧评分hash回首页。组件导航也先解析别名再更新hash与React状态。

`App` 启动时预热并常驻首页与 `ModelPage`；模型模块经React.lazy/Suspense载入，实际 GLB解析、纹理解码与着色器编译参与准备状态。路由通过 `active` 与隐藏容器切换模型可见性，不卸载其场景；动作/神态按route组合，不再渲染独立 `IntroPage`。首页 `useEntryPlayback` 在session首次进入时播放入场，结束/跳过/错误继续后同页切到用户循环视频，不跳模型；`nanfeng-lion:intro-seen:v1` 防止返回/刷新重复自动播放。模块级状态为存储不可用提供当前页面内回退，显式重播递增播放器key并滚到首屏，`VideoStage` 仍负责播放阻止、错误提示和离页暂停。

首页首屏后先是《岭南醒狮志》，再由 `HomeCulture` 呈现文化摄影与文字。当前 `HomePage.exploreCulture` 使“探索更多”和向下文化入口滚到 `#homeLionBook`，扣除实际顶栏高度；2026-10-14一度跳转结构的行为属于旧版本。`IntersectionObserver` 触发轻微淡入/位移，减少动态偏好或缺少观察器时直接显示；卸载断开观察器和媒体查询监听。四页 `BrandLockup` 共用同一PNG狮头，尺寸34–52px并与品牌文字居中对齐；导航条不再包含旧大狮头。2026-10-14来源：`HomePage.jsx`、`App.jsx`。

2026-10-12探索按钮改用用户金色书法的透明运行PNG，当日`aria-label="探索更多"` 保留可访问名称和文化滚动行为；2026-10-14曾将该点击改为跳结构，后续首页史册改版又恢复为滚到史册，字图与可访问名称保留。字图绝对定位于框的中心，箭头独立定位，不再参与文字居中分配。桌面 `entry-copy` 宽度取原标题宽度与按钮宽度的平均值，标题、按钮和中英文辅助文字共享中线，实现原标题略左、按钮及辅助文字略右；中文辅助文案以CSS字距取代文本中的重复不换行空格。原标题悬浮/鼠标跟随仍由原组件维护，减少动态时使用静态位置。来源：`HomePage.jsx`、`home.css`、书法素材说明；2026-10-12的1024/1366/1920/2560、390及1920推开设置审查图见当日任务日志。

## 全局导航与参数生命周期

`App` 在章节之外保持唯一SiteHeader、设置状态和稳定header/trigger/panel refs；四章Hash路由不变，第五项仅toggle，切页不重建顶栏/参数壳。首页五项显示完整标题与辅助文字，章节页仅显示同一组五个原SVG并收拢到右侧，返回首页展开；按钮的aria-label/aria-current保持。图标在首页和章节页始终为朱红`#d4382a`，紧凑导航以当前icon的`::after`红线标记章节。导航选择包括当前首页都会滚到首屏，sticky导航在文化长页仍可用；旧顶/底导航与搜索菜单已删除。2026-10-14来源：`App.jsx`、`SiteHeader.jsx`、`ChapterNav.jsx`、`chapters.js`、`navigation.css`。

`features/navigation/useNavigationMotion.js` 用FLIP记录切页前实际横坐标，React布局后用WAAPI `translateX`作水平补间，保留原SVG节点与运行资产。默认`navigationDuration:720`，范围200–1600ms、步长10；`smooth`为`cubic-bezier(0.65,0,0.35,1)`，`swift`为`cubic-bezier(0.22,1,0.36,1)`，`soft`为`cubic-bezier(0.4,0,0.2,1)`。快速再次导航先读取当前合成位置，再取消前次动画并接续；useChapterRoute在同一hashchange回调内先捕获、再更新React路由，使原生历史导航共用路径，避免独立监听器之间的提交时序。页面宽度或相关参数变化、开启减少动态效果和卸载均清除动画；onfinish撤销WAAPI填充并移除will-change，卸载断开ResizeObserver及媒体查询监听；路由hook清理hash监听。直接进入章节或减少动态偏好时直接使用目标布局，不强行补入场动画。来源：该hook、`App.jsx`。

设置常挂在App壳右侧，按外观、导航、动画、布局四个tab分页。打开时四个tabpanel保留DOM关联，用hidden只显示当前页；页签使用aria-selected、aria-controls、aria-labelledby及单一可Tab聚焦项，左右方向键/Home/End自动选择并聚焦。内容独立滚动，header/tabs/footer独立固定区域，恢复默认按钮不随内容滚走。关闭时组件返回null而组件状态仍保留，重开保持当前分类，刷新回到外观；关闭/Escape仍返回设置入口焦点。纸色、朱红与金线界面只读参考`E:/Software Development/WebPage`，未修改该工程。来源：`DeveloperSettingsPanel.jsx`、`developer-settings.css`、`App.jsx`。

推开预留实际宽度，剩余不足900px临时覆盖且保留偏好。顶/侧栏材质alpha和filter分别调节，避免整体opacity淡文字；页面背景延伸到顶栏后方。设置布局ResizeObserver、窗口/键盘事件在关闭或卸载时清理；video与canvas在参数变化时保持同一DOM实例。页签规范参考[WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)，动画参考[MDN Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)和[MDN cubic-bezier](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function/cubic-bezier)。

## 模型服务接口

2026-10-19 运行模型为 `source/public/assets/models/lion-structure-optimized.glb`，由 `assetPaths.model`/`media.model` 引用；旧单狮头原字节归档于 `source/models/lion-head-overall-v1.glb`，不再发布。新模型来自用户提供的 `model/醒狮_保留UV_三角转四边_优化.blend`，输入保留原位置、不改写或提交。导出检查见 `source/references/lion-structure-model.json`。

`ModelPage` 动态 import `createLionScene`，传入全页画布 `container`、左侧交互 `interactionElement`、布局观察 `layoutElement`，以及 `modelUrl`、`signal`、`active`、`autoRotate`、六组 `hotspots` 和状态/旋转/表面选择/投影回调。服务使用本地 npm Three.js、OrbitControls、GLTFLoader、Raycaster和锁定的`three-mesh-bvh@0.8.0`，返回 `setActive(value)`、`setAutoRotate(value)`、`focusOn({ id, target, distance, point })`、`resetView()` 与 `dispose()`。

`App` 在启动阶段预热并保留同一画布；`ModelPage` 在章节激活且文档可见时启用场景，离页或后台只取消后续渲染帧。返回章节时更新尺寸并继续绘制，不销毁/重建 WebGL 上下文。组件 effect 为每次加载创建 AbortController；重试、卸载或场景故障才 abort 并 dispose。容器 WeakMap 保护单容器所有权，StrictMode重放 effect 前释放旧实例；流式读取可报告真实下载进度，GLTF解析异步返回后再次核对取消状态，并释放已取消的新场景。

结构页为左模型、右资料的电脑双栏。右侧唯一 `structurePanel` 集中标题、加载状态、旋转/复原控件、六组目录、工艺/文化切换和来源，详情在卡内滚动；左侧提供模型、实际投影标签和独立输入区域。`sceneContainer` 为 `modelStage` 直属子级并覆盖整页，`sceneFrame` 不限定16:9且允许溢出。透明画布不拦截资料卡、控件或导航，OrbitControls与表面拾取都绑定独立 `scene-interaction`。

`camera.setViewOffset` 以左侧交互区构图，再以画布相对交互区的负偏移延展全页投影；尺寸变化观察容器、交互区和布局。完整醒狮全景按模型包围盒拟合，用户手动操作后的视角不因普通resize重置，复原重新计算全景。像素比同时受设备DPR、1.5、约260万像素预算和 `MAX_RENDERBUFFER_SIZE` 限制。PBR金属饰件使用 `RoomEnvironment` 经 PMREM生成的中性反射贴图，曝光1、半球光0.4、主光2、轮廓光0.6，不增加地面或可见内场景。

六组目录来自 `lion-structure.json`，以 `objectNames` 网格名前缀标记真实部件，以 `surfaceRegions` 椭球标记共用头壳里的眼部等可见语义。Raycaster命中最前方真实模型表面后回调 `onSelectPart(id, point)`；模型选择和目录选择共享React状态与聚焦入口。点击实际部件后暂停自动旋转并在左侧放大；拖动超过手势阈值、指针取消/离开或空白点击不选择部件。默认自动旋转关闭，用户仍可显式开启。

2026-10-19性能修复只为当前模型的mesh实例赋值`acceleratedRaycast`，几何使用indirect BVH保留原索引/材质组，`firstHitOnly`求最近命中，不修改全局原型。多锚点诊断只在相机稳定后更新；转动时反复扫描全部三角会造成严重CPU阻塞，已由CPUProfile证实。按需单一RAF在输入/阻尼/补间/自动旋转/尺寸变更时继续，稳定后一次刷新观察并停绘，既无固定轮询，也不销毁已预热实例。

`onProjectParts([{id,x,y,visible}])` 在绘制后给出源focusTarget的交互框局部投影，ModelPage用DOM refs更新六个标签和SVG点/连线，不逐帧React setState。左右边列按锚点高度分散并限制间距/框内位置；交互框小于540px用两字短名，全名仍在title/aria-label及右侧目录。标签只按视锥/框内判断显示，背面遮挡不每帧射线探测；真实点击仍以最近表面命中分类。标签的pointerdown不传播，Enter/Space按钮行为与目录共用聚焦。

目录 `target`、`surfaceRegions.center/radii` 与 `pickPoints` 使用源 glTF 场景坐标；服务经模型的 `localToWorld`/`worldToLocal` 换算。实际点击的 `point` 已是当前世界坐标，直接作为聚焦目标。`distance` 使用模型最长边归一到1.78后的世界距离。聚焦与复原在唯一 render loop 内补间相机与controls target，减少动态偏好下直接定位；拖动会中断补间并停止自动旋转。只读 canvas dataset 发布实际相机距离、目标投影、可命中部件投影和补间状态，供真实浏览器核对，未暴露全局测试API。

## 清理与回退

`dispose` 幂等：中止fetch、清加载超时、稳定观察计时器与RAF，断开ResizeObserver，移除resize、controls、WebGL上下文、pointer及窗口blur监听，销毁OrbitControls。随后关闭纹理图像、释放几何BVH与纹理/材质/几何及骨骼纹理，清空场景，释放PMREM环境渲染目标和renderer，并丢失/移除画布。临时RoomEnvironment和PMREMGenerator在环境生成后立即释放；GLTF解析晚到的已取消场景也需独立释放。

GLB请求、解析、准备超时、WebGL丢失或绘制失败回报error，保留预览与“重新载入”；重试创建新场景，正常章节往返保留原实例。修改服务后运行资产检查、构建及相关 `app.spec.js`、`startup-loading.spec.js` 与设置回归，检查实际像素、表面点选、目标投影、拖动/空白、透明背景、不同电脑窗口、离页暂停重入、失败重试和上下文丢失。2026-10-11旧版本“离页释放并contextLost”的断言属于历史，不再表示当前预热架构；旧单狮头越过16:9上下边界的形状阈值亦不适用于当前完整醒狮。

本轮初版67MB导出曾在基线 `main@1b193a5` 加工作区通过语义/GLB/文化相机元数据3项与开发定向5项（透明融合、1366双栏、列表及画布复用、三个真实表面聚焦、拖动与空白不误选）。它们不代替最终压缩模型、生产预览或其他受影响场景验收；最终结果以 [[日志/功能添加/2026-10-19-结构新模型与部件聚焦.md|本轮交付日志]] 为准。
