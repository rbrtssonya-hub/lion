# 前端与三维生命周期

适用融合首页、文化长页、全局导航/设置和整体/结构示意模块。当前行为以源码核实；2026-10-14新增图标收拢与设置分页，并将探索更多改为跳结构。此前独立intro/structure路由、视频转模型和探索按钮文化滚动行为已替代。自2026-10-14起开发与验收仅以电脑端为目标，历史手机结果只追溯当时实现。历史验证不证明本轮改动已通过，正式回归结果由交付日志另记。

## 路由与页面

Hash现行路由为 `#/entry`、`#/model`、`#/action`、`#/state`，导航名称为首页、结构、动作、神态；“结构”替代旧名“狮头与结构”，不改变model路由，顶部仍不显示章节数字。旧 `intro`→`entry`、`structure`→`model`，初始化和hashchange时用 `replaceState` 规范别名，不新增历史记录；空、非法和旧评分hash回首页。组件导航也先解析别名再更新hash与React状态。

`App` 用React.lazy载入整体页，其余页面按route组合；不再import/渲染独立 `IntroPage`。首页 `useEntryPlayback` 在session首次进入时播放入场，结束/跳过/错误继续后同页切到用户循环视频，不跳模型；`nanfeng-lion:intro-seen:v1` 防止返回/刷新重复自动播放。模块级状态为存储不可用提供当前页面内回退，显式重播递增播放器key并滚到首屏，`VideoStage` 仍负责播放阻止、错误提示和离页暂停。

首页首屏之后的 `HomeCulture` 直接呈现四组真实摄影与文化文字。“探索更多”经App的导航入口跳到结构 `#/model`；“向下了解醒狮文化”仍滚到文化区。`IntersectionObserver` 触发轻微淡入/位移，减少动态偏好或缺少观察器时直接显示；卸载断开观察器和媒体查询监听。四页 `BrandLockup` 共用同一PNG狮头，尺寸34–52px并与品牌文字居中对齐；导航条不再包含旧大狮头。2026-10-14来源：`HomePage.jsx`、`App.jsx`。

2026-10-12探索按钮改用用户金色书法的透明运行PNG，当日`aria-label="探索更多"` 保留可访问名称和文化滚动行为；2026-10-14只将该点击改为跳结构，原字图及布局保持。字图绝对定位于框的中心，箭头独立定位，不再参与文字居中分配。桌面 `entry-copy` 宽度取原标题宽度与按钮宽度的平均值，标题、按钮和中英文辅助文字共享中线，实现原标题略左、按钮及辅助文字略右；中文辅助文案以CSS字距取代文本中的重复不换行空格。原标题悬浮/鼠标跟随仍由原组件维护，减少动态时使用静态位置。来源：`HomePage.jsx`、`home.css`、书法素材说明；2026-10-12的1024/1366/1920/2560、390及1920推开设置审查图见当日任务日志。

## 全局导航与参数生命周期

`App` 在章节之外保持唯一SiteHeader、设置状态和稳定header/trigger/panel refs；四章Hash路由不变，第五项仅toggle，切页不重建顶栏/参数壳。首页五项显示完整标题与辅助文字，章节页仅显示同一组五个原SVG并收拢到右侧，返回首页展开；按钮的aria-label/aria-current保持。图标在首页和章节页始终为朱红`#d4382a`，紧凑导航以当前icon的`::after`红线标记章节。导航选择包括当前首页都会滚到首屏，sticky导航在文化长页仍可用；旧顶/底导航与搜索菜单已删除。2026-10-14来源：`App.jsx`、`SiteHeader.jsx`、`ChapterNav.jsx`、`chapters.js`、`navigation.css`。

`features/navigation/useNavigationMotion.js` 用FLIP记录切页前实际横坐标，React布局后用WAAPI `translateX`作水平补间，保留原SVG节点与运行资产。默认`navigationDuration:720`，范围200–1600ms、步长10；`smooth`为`cubic-bezier(0.65,0,0.35,1)`，`swift`为`cubic-bezier(0.22,1,0.36,1)`，`soft`为`cubic-bezier(0.4,0,0.2,1)`。快速再次导航先读取当前合成位置，再取消前次动画并接续；useChapterRoute在同一hashchange回调内先捕获、再更新React路由，使原生历史导航共用路径，避免独立监听器之间的提交时序。页面宽度或相关参数变化、开启减少动态效果和卸载均清除动画；onfinish撤销WAAPI填充并移除will-change，卸载断开ResizeObserver及媒体查询监听；路由hook清理hash监听。直接进入章节或减少动态偏好时直接使用目标布局，不强行补入场动画。来源：该hook、`App.jsx`。

设置常挂在App壳右侧，按外观、导航、动画、布局四个tab分页。打开时四个tabpanel保留DOM关联，用hidden只显示当前页；页签使用aria-selected、aria-controls、aria-labelledby及单一可Tab聚焦项，左右方向键/Home/End自动选择并聚焦。内容独立滚动，header/tabs/footer独立固定区域，恢复默认按钮不随内容滚走。关闭时组件返回null而组件状态仍保留，重开保持当前分类，刷新回到外观；关闭/Escape仍返回设置入口焦点。纸色、朱红与金线界面只读参考`E:/Software Development/WebPage`，未修改该工程。来源：`DeveloperSettingsPanel.jsx`、`developer-settings.css`、`App.jsx`。

推开预留实际宽度，剩余不足900px临时覆盖且保留偏好。顶/侧栏材质alpha和filter分别调节，避免整体opacity淡文字；页面背景延伸到顶栏后方。设置布局ResizeObserver、窗口/键盘事件在关闭或卸载时清理；video与canvas在参数变化时保持同一DOM实例。页签规范参考[WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)，动画参考[MDN Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)和[MDN cubic-bezier](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function/cubic-bezier)。

ResizeHandle使用整边界hit area和中央hover/focus grip，pointer capture及窗口fallback处理指针，单RAF合并move。preview不写存储；pointerup提交最新值，Escape/pointercancel/lostcapture/blur/pagehide/隐藏/卸载恢复初值、取消RAF、释放capture、移除监听及全局选中禁用状态。方向键/Shift/Home/End与双击也经同一参数提交；Escape取消拖动不同时关闭侧栏。

## 模型服务接口

`ModelPage` 通过动态 import 加载 `createLionScene`，传入全页画布 `container`、中央交互 `interactionElement`、页头 `layoutElement`，以及 `modelUrl`、`signal`、`autoRotate`、`onStatus`、`onAutoRotateChange`。服务使用本地 npm Three.js、OrbitControls、GLTFLoader，返回 `setAutoRotate(value)`、`focusOn({ target, distance })`、`resetView()` 与 `dispose()`；聚焦和复原共用现有 render loop 内的单一补间。

组件 effect 创建 AbortController，卸载时 abort 并 dispose；服务用容器 WeakMap 保护单容器所有权，避免快速切换和 StrictMode重复 effect 创建多份活跃场景。GLB读取支持流式进度，取消时中止 fetch，解析返回后仍核对取消状态。

整体页 `showGuide` 控制同页 `structureLayer`；右侧结构工艺始终展示，“查看结构示意/关闭结构示意”仅开关状态，复原关闭示意并调用resetView，不更改route或重建renderer。拖动触发controls的start事件，会停止自动旋转并通知React；旋转按钮经ref更新已挂载服务，加载重试通过 `loadAttempt` 重新跑effect。

2026-10-11第一次透明改造删除CSS光晕、环纹、网格和Three.js圆形地面，renderer显式 `setClearColor(0x000000, 0)`，但canvas仍受中央16:9尺寸限制；透明背景不代表模型可以越过画布边界。现行修正把 `sceneContainer` 移为 `modelStage` 直接子级并覆盖整页，中央 `sceneFrame` 无16:9限制且允许溢出，独立 `scene-interaction` 绑定OrbitControls。整页canvas不接收指针事件，档案卡、热点、导航和控制按钮各自继续接收交互。

中央列高度桌面为 `max(680px, 100svh - 240px)`，900px以下为 `max(560px, 100svh - 230px)`；采用 `align-self: start`，避免长档案卡拉高交互区域。标题、说明和按钮为绝对定位浮层。相机通过 `setViewOffset` 以中央交互区宽高构图，再以全页画布相对交互区的负偏移延展投影，不使用中央裁切区域；尺寸变化观察画布容器、交互区和页头并更新投影。DPR最多2，进一步受 `MAX_RENDERBUFFER_SIZE` 约束，手机长页会按硬件最大缓冲区降低DPR。来源：`ModelPage.jsx`、`model.css`、`lionScene.js`。

2026-10-11全页画布修正曾在Windows PowerShell、Node24.16.0/npm12.0.1、Chrome、`main 594dd45` 加任务工作区通过资产8项、构建和开发/生产预览各14项e2e。真实滚轮与WebGL像素确认模型包围高度增长超过15%，旧16:9及中央 `sceneFrame` 上下边界外各有超过100个模型像素，默认四角透明。该结果追溯历史修正；2026-10-12同页结构和融合首页以本轮各19项为准。越界绘制仍须实际像素验收，不能用透明清屏或删CSS边框替代；历史证据见 [[日志/UI修改/2026-10-11-模型全页画布与裁切修正.md|全页画布修正日志]]。

## 清理与回退

`dispose` 幂等，取消加载与动画帧，移除 resize/controls/WebGL上下文监听，关闭图像、释放纹理/材质/几何、清空场景并释放/移除 renderer。模型解析后已取消的对象也需释放；将来加载多 scene 或骨骼纹理时保持同样处理。

GLB请求、解析或 WebGL失败会回报 error，模型页面保留预览与重试。修改服务后至少验证快速进出模型、模型/结构切换、重试、WebGL不可用和上下文丢失。2026-10-11全页修正回归确认整体/结构共享单canvas、离页后WebGL contextLost、重入、下载失败重试和原交互正常；没有量化内存/GPU释放量，也没有直接实测组件主动中止进行中的下载或意外WebGL上下文丢失后的恢复。

## 内容边界

六个热点来自 `src/data/lion-structure.json`，位置为语义百分比叠层；结构深度来自页面示意状态，没有真实分离模型部件。此模块还不提供动作统计、神态规则或评分器。
