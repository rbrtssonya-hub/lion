# 已知问题

最新六章浏览器结果没有未处理运行报错。以下是已确认的源资产与表达限制，不能写成已经修复。

## 未解决问题与影响

| 现状 | 影响与边界 |
| --- | --- |
| 源模型破面、部分共面发射面 | 原生顶点和对象保留，未全面重拓扑或补面，某些视角仍可能有几何瑕疵。World对标记发射面的克隆材质设 `polygonOffset`减轻闪烁，没有删面或移动源节点。 |
| Blender毛发/程序材质不能原样带入glTF | 长毛沿实际曲线隔根采样成带状网格，短绒导出30,000条父毛路径；约212万子毛未逐根还原。Wave→Bump微织纹未烘焙，网页与离线源渲染密度、细纹有差异。 |
| AI艺术图不是精确模型或历史实物 | 六张主图保持终点大构图，局部轮廓、材质和纤维存在转译差异；淡化不是逐像素配准。文化插画不能证明模型内部骨架、实测运动或历史细节。 |
| 资源较重 | GLB为35,159,152字节、约162万模型三角面，另有PNG与GPU纹理成本。初次下载、解码和渲染依机器而变，现有证据不承诺通用帧率。 |
| Three依赖块提示 | 既有构建成功但Three块超过500KB提示仍在；`manualChunks`已分离Three相关依赖。这不是构建失败，本次记忆任务不改加载方案。 |
| 数字尺度与采样口径 | 包围盒尺寸未校准实物单位；轮廓、分箱、UV是样本，不是精确截面/完整UV岛；色带按采样表面积估计，不是截图像素比例。 |
| 模型无骨骼、绑定或表演动画 | 敛口/微启/张口、眉眼及须势变化只在艺术图解中解释，不能视为GLB可驱动表情。 |

依据为 `MODEL_AUDIT.md` 的源/派生资产审计、`LionWorld.js` 的材质与渲染实现、`VISUALIZATION_DESIGN.md` 的图像和测量边界。用户要求保持完整模型，几何拆分、爆炸动画或全面修模不是当前实现。

## 复现与临时处理

- **源几何与材质差异**：首页拖动/缩放完整模型，或在淡化前观察六个终点；审计中的源/派生预览可用于对比毛发密度。现用材质深度偏移降低共面闪烁；进入章节后艺术主图承接展示，但不代表底层所有源面已修复。不要自动覆盖源 `.blend`。
- **构图差异**：对照 `artifacts/handoff/references/<id>.png` 和 `public/images/chapters/<id>.png`；完整contain和固定3:2避免二次裁图。更改FOV、模型缩放或终点后须重新捕获并生成对应主图，旧匹配证据不再充分。
- **加载与块提示**：首次HTTP访问读取GLB，后续缓存、单World复用和图片阶段暂停RAF减轻成本。块提示在以后需要构建时再观察，本次只读取已有证据，不为记忆重跑性能或构建检查。
- **数据误读**：数据页已标模型单位、方法和样本数；须图只抽取部分有效分箱，口部投影不模拟关节。`culture.js`区分文化依据与造型观察，地方资料不扩大成所有流派规则。
- **运行与目标**：须用Vite或静态HTTP服务，不能文件协议直开 `dist/index.html`。实际端口以启动输出为准，历史5175/4175不代表服务现在存活。桌面是授权目标，不把手机未优化列成本轮待修缺陷。
