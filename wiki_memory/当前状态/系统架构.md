# 系统架构

## 模块职责与边界

- 根 `index.html` 为唯一 HTML 入口，`src/main.jsx` 以 React `createRoot` 和 `StrictMode` 挂载 `App`。`App` 根据章节组合页面，未使用 iframe 桥接。依赖由 `package.json`/`package-lock.json` 管理；源码目录为 `src/`。
- `features/home` 包含同页入场/循环视频状态与文化长页；`features/intro/IntroPage.jsx` 已删除。`model` 仅整体页，结构示意为同页状态；`chapters` 保留动作/神态占位。公共品牌、导航、播放回退、标题在 `components`，页面数据与媒体在 `config`/`data`，图形服务在 `services/lionScene.js`。
- 2026-10-12 `ChapterNav`、搜索和菜单统一从配置生成入场/整体/动作/神态四章；首页底部为整体/动作/神态三个入口。四页 `BrandLockup` 共用小号 `EntryLionEmblem` PNG，位于左上品牌文字左侧，导航条移除旧大狮头与其占位。红金牌签、云纹、工具框、挂穗和原标题 `TitleMotionLayer` 保留。
- React 管热点、三栏信息面板和加载状态；`ModelPage` 的 effect 挂载和释放 Three.js 服务，并把热点目标传给服务完成聚焦/复原。服务管理 renderer、controls、GLB载入、单一渲染循环内的相机补间与GPU资源，避免界面组件承担场景清理细节。
- 本地Hash现行路由为 `entry/model/action/state`；旧 `intro`→`entry`、`structure`→`model` 并以 `replaceState` 规范Hash，不增加历史项，非法地址和已删除评分回首页。白名单从 `chapters` 派生，`useChapterRoute` 同步 `hashchange` 与React状态，没有后端章节路由。

## 数据流与依赖

- 导航点击 → Hash/React route → `App`选页。首页 `useEntryPlayback` 以 `nanfeng-lion:intro-seen:v1` 记录session：首次入场 → 结束/跳过/错误继续 → 用户循环视频，全程保持 `entry`；返回或刷新不自动重复，显式重播重新挂载入场播放器。存储不可用时有当前页面内的回退，`VideoStage` 管播放阻止/错误提示及离页暂停。
- `HomeCulture` 从 `home-culture.js` 读取四组文化图文与摄影许可，从 `media` 取本地图片，首屏CTA仅滚到 `#homeCulture`。`IntersectionObserver` 让图文轻微入场，减少动态偏好或观察器不可用时直接显示；卸载断开观察器和媒体查询监听。来源和许可在各图注及页尾公开，内容不创建额外章节。
- `ModelPage.showGuide` 在整体页控制 `structureLayer` 的可见性；“查看结构示意/关闭结构示意”和复原按钮不导航，canvas与右侧结构工艺卡保持挂载。复原关闭示意并重置视角，结构滑杆仍是合并网格的语义示意。
- 模型页通过 `React.lazy` 载入，effect再动态导入 `lionScene.js`；服务使用本地npm Three.js、OrbitControls和GLTFLoader。服务 `fetch` 下载GLB，`parseAsync` 解析，成功后回报 `ready`，失败保持预览和重试；`focusOn` 与 `resetView` 复用同一个 render loop，不创建第二套 RAF。
- 2026-10-11全页画布修正：`sceneContainer` 为 `modelStage` 直接子级，透明canvas覆盖整页，`pointer-events: none`；中央 `scene-interaction` 独立承接OrbitControls，热点、回退与控件继续由React维护。`sceneFrame` 填充中央列并允许溢出，取消16:9与裁切；标题、说明和控件绝对定位，中央列桌面高度为 `max(680px, 100svh - 240px)`，900px以下为 `max(560px, 100svh - 230px)`，不随档案卡内容伸高。
- 渲染与交互尺寸分开：`camera.setViewOffset` 用中央交互区域的宽高定义构图，再用相对全页画布的负偏移扩展可见投影，避免中央矩形成为绘制边界。`ResizeObserver` 观察画布容器、交互层和页头，resize同时更新投影、画布尺寸和DPR；DPR上限2，并按 `MAX_RENDERBUFFER_SIZE` 限制绘制缓冲区。renderer继续 `alpha: true` 和透明清屏，scene只保留模型与照明，无地面；退出时仍取消单一RAF、下载和观察器并释放图形资源。
- 媒体原路径来自 `assetPaths.js`，`media.js` 加 Vite `BASE_URL`；热点JSON直接导入 `ModelPage`。本次读取现用GLB的JSON头，确认1个mesh/1个node，mesh名为 `LionHead_Overall_MergedMesh`；结构层是页面语义示意，没有真实独立部件拆分。
- 离开模型页 → `AbortController.abort()` / `dispose()`；服务取消fetch和动画帧、断开观察器、移除监听、释放controls/纹理/材质/几何/renderer。`WeakMap` 保护容器所有权，解析后若已取消也释放模型。详见 [[知识/前端与三维生命周期.md|生命周期知识]]；源码清理存在不等于已量化无内存泄漏。

## 运行与部署

- Vite配置 `base: './'`、`publicDir: 'source/public'`、开发5173/预览4173、`outDir: 'dist'`、`emptyOutDir: true`。`source/public` 静态文件原样进入dist，非public创作文件不随构建发布。
- npm网页启动与 `scripts/` 离线模型/PSD制作工具分离；Python或Blender不是 `npm run dev` 的启动前提。Windows `runStart.cmd` 切换到脚本目录后调用同一 `npm run dev -- --open`，不构成第二套网页入口。
- `src/`应用、`tests/`验证、`scripts/`辅助工具、`docs/`开发说明、`source/`资源、根 `wiki_memory/`工程记忆互有边界，只有一份当前事实源。
- 本地预览不是正式部署。托管平台、域名、发布方式尚未决定；Hash路由通常不要求章节路径回退，实际部署基址和WebGL环境仍需目标环境验收。
