# 系统架构

## 模块职责与边界

React/Vite 负责页面，Three.js 加载真实模型，GSAP 协调相机与图版。`AtlasExperience.jsx` 管理选择、主图/讲解图解码、四档主图、交接、取消和浮窗开合；`LionBreakdownStage.jsx` 将当前竖版信息图作为整图点击入口，`LionDetailModal.jsx` 提供分节内容、来源和键盘/遮罩关闭。`lionBreakdowns.js` 保存图片路径、正文和资料来源。`ModelCanvas.jsx` 创建唯一 `LionWorld`；`LionWorld.js` 管理 GLB、拾取、相机、整窗渲染、暂停及清理。`PartRegistry.js` 保留原生部位映射，`layout.mjs` 选择最近主图比例并计算完整图像与相机光圈。

`CulturalPanel.jsx`、`culture.js`、旧分析算法和文化图仍在工程中，但当前页面不挂载它们。右侧文化文字仅由用户点击图版后挂载到浮窗。底部六个 PNG 入口及各章宽屏主图由 `parts.js` / `chapters.js` 指向；六张竖版图独立位于 `public/images/lion-info/`。

## 数据流与依赖

1. `ModelCanvas → LionWorld → GLTFLoader/DRACOLoader` 加载本地 `public/models/lion.glb` 并建立部位映射，源 `.blend` 不覆盖。
2. 点击后相机按原位置、目标和 FOV 飞向部位，三维画布覆盖窗口；根据窗口比例选择16:10、16:9、约1.882或约2.37主图并解码。`frameLayout()` 根据图片的完整 contain 区域计算中央3:2光圈，`setViewOffset` 扩展到窗口边缘。
3. 图像和透明模型层同步淡化，模型层位于图像之上；图片完成替换后模型隐藏并暂停 RAF，GSAP 等比缩放图片到 `(0,0)`、导航左移。`study` 阶段同时挂载右侧 ImageGen 图版，浮窗正文仅在点击后打开；返回和切章恢复画幅后接回模型。快速操作以 epoch 取消旧流程。
4. 四档每章宽屏图在 `public/images/fullscreen/`，由内置 imagegen 以真实终点截图为构图参考分别生成。六张信息图在 `public/images/lion-info/`，以对应部位模型视图为参考，切章时与主图一起预解码。宽屏比例变化时检查当前章节和最新窗口后切换；加载失败保留当前已解码主图。

依赖 React 19、Three.js 0.186、GSAP 3.15、three-mesh-bvh 和 Vite 8；版本以 `package-lock.json` 为准。静态资源本地提供，无后端或外部运行时 API。

## 运行与部署

Node.js 22.12+，建议24；`npm install`、`npm run dev`，或 `启动网页.cmd`；`npm run build` 和 `npm run preview`。使用终端输出端口，并以 HTTP 提供 GLB、Draco、图片与字体。当前桌面优先，窄屏只将文化浮窗改为纵向布局；未扩大到整个页面的手机优化。
