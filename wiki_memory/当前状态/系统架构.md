# 系统架构

## 模块职责与边界

- 根 `index.html` 为唯一 HTML 入口，`src/main.jsx` 以 React `createRoot` 和 `StrictMode` 挂载 `App`。`App` 根据章节组合页面，未使用 iframe 桥接。依赖由 `package.json`/`package-lock.json` 管理；源码目录为 `src/`。
- `features/home` 为视频首页，`intro` 为入场，`model` 共用整体/结构，`chapters` 为动作/神态/评分占位。公共导航、播放回退、标题在 `components`，页面数据与媒体在 `config`/`data`，图形服务在 `services/lionScene.js`。
- React 管热点、信息面板和加载状态；`ModelPage` 的 effect 挂载和释放 Three.js 服务。服务管理 renderer、controls、GLB载入与GPU资源，避免界面组件承担场景清理细节。
- 本地 Hash 路由允许 `entry/intro/model/structure/action/state/score`，非法地址回首页。`useChapterRoute` 同步 `hashchange` 与React状态；没有章节后端路由。证据：`src/hooks/useChapterRoute.js`、`src/config/chapters.js`。

## 数据流与依赖

- 导航点击 → Hash/React route → `App`选页；入场播放结束 → `model`。`VideoStage` 对阻止播放/媒体错误给手动播放或继续模型的按钮，离开时暂停视频。证据：`App`、`IntroPage`、`VideoStage`。
- 模型页通过 `React.lazy` 载入，effect再动态导入 `lionScene.js`；服务使用本地npm Three.js、OrbitControls和GLTFLoader。服务 `fetch` 下载GLB，`parseAsync` 解析，成功后回报 `ready`，失败保持预览和重试。
- 媒体原路径来自 `assetPaths.js`，`media.js` 加 Vite `BASE_URL`；热点JSON直接导入 `ModelPage`。本次读取现用GLB的JSON头，确认1个mesh/1个node，mesh名为 `LionHead_Overall_MergedMesh`；结构层是页面语义示意，没有真实独立部件拆分。
- 离开模型页 → `AbortController.abort()` / `dispose()`；服务取消fetch和动画帧、断开观察器、移除监听、释放controls/纹理/材质/几何/renderer。`WeakMap` 保护容器所有权，解析后若已取消也释放模型。详见 [[知识/前端与三维生命周期.md|生命周期知识]]；源码清理存在不等于已量化无内存泄漏。

## 运行与部署

- Vite配置 `base: './'`、`publicDir: 'source/public'`、开发5173/预览4173、`outDir: 'dist'`、`emptyOutDir: true`。`source/public` 静态文件原样进入dist，非public创作文件不随构建发布。
- npm网页启动与 `scripts/` 离线模型/PSD制作工具分离；Python或Blender不是 `npm run dev` 的启动前提。
- `src/`应用、`tests/`验证、`scripts/`辅助工具、`docs/`开发说明、`source/`资源、根 `wiki_memory/`工程记忆互有边界，只有一份当前事实源。
- 本地预览不是正式部署。托管平台、域名、发布方式尚未决定；Hash路由通常不要求章节路径回退，实际部署基址和WebGL环境仍需目标环境验收。
