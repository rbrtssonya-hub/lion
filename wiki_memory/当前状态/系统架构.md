# 系统架构

项目是桌面醒狮文化交互展览，React + Vite 管理页面，Three.js 管理真实模型，GSAP 管理相机、交接和文字动效。入口 `src/main.jsx` 加载 `experience.css`，`App.jsx` 导向 `AtlasExperience`；旧研究组件不是当前入口。

## 模块职责与边界

| 模块 | 当前职责与边界 |
| --- | --- |
| `AtlasExperience.jsx` | 六章选择、图片解码、状态切换、错误恢复和返回；递增epoch与可取消tween使快速操作以最后一次为准。首页无文化面板，左上印章已移除。 |
| `ModelCanvas.jsx` | 唯一Three容器，创建一个 `LionWorld`，加载一次GLB，固定相机比例1.5；开发环境才暴露诊断对象，卸载时释放。 |
| `LionWorld.js` | GLTF/Draco加载、材质适配、光照、OrbitControls、BVH拾取、相机、暂停RAF和GPU清理；`flyToPart / restoreOverview / cancelFlight`协调镜头，节点不作分离位移。 |
| `PartRegistry.js` | 按 `parts.js` 映射原生部件；全部原生顶点测包围盒，最多7,000点作轮廓抽样，排除派生毛发；按 `sourceName` 聚合原始对象，首次分析后缓存。 |
| `CulturalPanel.jsx` | “文化图解 / 形态数据”双页签、GSAP标题、编号图解、分项解释滚入阅读区、键盘页签和独立滚动；数据图读取分析结果。 |
| `parts.js / chapters.js / culture.js` | 分别定义测量/拾取范围、主图与标题、文化插画/步骤/背景/来源；内容与渲染实现分开。 |

用户确定保留完整模型、桌面展示、艺术入口和图文文化内容；Agent在此范围采用固定3:2主画幅、同构图淡化、编号图解和双页签，均已实现。保留较重模型与独立高分辨率图片，艺术图和实测数据分开说明。[依据：`README.md`、`VISUALIZATION_DESIGN.md`及上述组件。]

## 数据流与依赖

1. `ModelCanvas → LionWorld → GLTFLoader/DRACOLoader` 读取本地 `public/models/lion.glb` 与解码器，建立注册表后通知React就绪。`source/科比blend.blend`保留，网页用派生GLB。
2. 六个 `public/images/navigation/<id>.png` 是image_gen艺术入口，不调用旧 `PartGlyph`。选择后 `travel` 相机按 `HANDOFF_FRAMINGS` 和真实边界飞向部位，同时分析网格并解码 `chapters/<id>.png`；织锦另读取实际UV与纹理。
3. `layout.mjs`令画幅宽高取3:2整数比例；终点参考与主图同为3:2。相机完成后 `handoff` 淡入完整contain主图，`study`隐藏模型层、停止RAF，随后显示文化栏。返回先恢复同镜头模型再回最初整体镜头；没有爆炸节点或网格拆解。
4. 文化页读取 `public/images/culture/<id>.png` 和 `culture.js`，三联、2×2或三行图对应编号区域；精准文字和交互由HTML实现。文化图与导航共十二张新增PNG，完整提示词、原始路径与哈希在 `artifacts/enrichment/`。
5. 数据页读取实际原生网格：眉径向包络、额饰/口齿中心投影、须宽度、云边移动平均、三轴尺寸。织锦UV来自实际属性，`textureStudy.js`读真实贴图和基础色，以采样三角表面积估计色带；不是屏幕像素占比。

主要依赖React19、Three.js0.186、GSAP3.15、three-mesh-bvh与lucide-react，构建用Vite8；版本区间见 `package.json`，锁定版本见 `package-lock.json`。模型、Draco、字体和十八张当前PNG均本地提供，无后端或外部运行时API；机构来源链接供读者主动打开。

## 运行与部署

- Windows PowerShell工作区，Node.js需22.12+，建议24；`npm install`、`npm run dev`，或双击 `启动网页.cmd`。默认Vite从5173递增，历史验证用5175，应以终端打印地址为准。
- `npm run build`生成 `dist/`；`npm run preview -- --port 4175`可本地预览。必须经HTTP并完整提供GLB、Draco、图片、字体，直接双击HTML不满足根路径资源加载。
- 当前交付为本地项目，无外部发布记录。主测试视窗1536×960，附1280×800和1920×1080桌面版面；手机优化不在目标。
- GLB实测35,159,152字节，约162万模型三角面；另有十八张艺术PNG，首次下载和GPU成本较高。模型只加载一次，图片阶段暂停3D；DPR上限1.6、1024阴影与BVH控制成本。Vite分离Three依赖块，仍有块体积提示。[依据：`MODEL_AUDIT.md`、`LionWorld.js`、`vite.config.js`。]
