# 系统架构

## 2026-10-15 当前加载与导航机制

- `index.html` 最前置同源加载iframe，`useStartupLoading` 汇总图像/字体/模块25%、视频首帧5%、模型35%、书册20%、图鉴15%准备任务。完成或明确失败且原动画最短时长结束才退出；没有跳转第二套入口。
- App永久挂载首页和模型，隐藏时offscreen/visibility hidden/inert，保留renderer及iframe；模型初次GLB解析/compileAsync/首绘在入场前完成，章节切换不重新编译。模型active与document.hidden暂停RAF；App真正卸载或重试仍abort并dispose全部资源。书册和图鉴按playbackEnabled与曝光控制，预热不播放、不消费首次资格。
- HomeLionBook/LionBookExperience/适配bridge负责尺寸和曝光，ThreeUI原纸页核心不改；初次0×0不能决定coarse策略，真实曝光才决定是否跳过。时间线独立SVG波浪、狮头与墨迹。
- `useNavigationMotion` 在捕获图案/文案/品牌时一并捕获同一`.navigation-surface`，按实际宽高FLIP；保留右侧首页，resize/减少动态/打断均清理旧WAAPI。
- `surfaceSettings.js` 定义7类材质，App展开全局CSS变量；`surface-settings.css` 对阅读/结构/动作/视频提示应用独立宽高/颜色/圆角/alpha/blur；顶栏和侧栏另有完整参数。设置左竖排分类、右滚动，旧统一透明度迁移为四处阅读偏好。
- 文化8项实景数据集中在home-culture.js、资产仍集中media/assetPaths，摄影署名许可与3个文化来源在首页底部可见。运行HTML/背景仅放source/public/assets/loading，原加载创作文件放source/design/loading。

以下为前次架构事实，涉及四项章节导航、离页销毁模型或懒到可见才初始化的旧行为以本节及本轮源码替代。实际结果见本轮UI日志。

## 模块职责与边界

- 首页首屏后 `.home-archive-scene` 由集中媒体配置/文档绝对基址承载用户最终醒狮背景，包住 `HomeLionBook` 与 `.home-archive-next` 下的 `HomeCulture`；后者同时承载透明探头装饰。图鉴上边线为跨区定位基准，狮头上露、爪尖下搭；两模块保持透明与原懒加载/轮播/官方书页数据关系。装饰读屏隐藏/无指针，书册provenance通过同一width变量留右侧位置；vw避免内外container的cqw不一致。小标题装饰仍复用 `LionArchiveOrnament`，未改iframe、官方包、Three引擎或导航。素材、提示词与真实性边界见来源说明。

- 前次双线合并保留首页史册sandbox srcDoc iframe、纵深照片引擎、用户PNG导航/五类设置及支线动作四段/神态单屏，30项资产/核心、246模块构建、电脑开发/生产各107项为该历史提交范围。本轮在 `main 3d2fbc1` 上进一步实现会话快翻、分块导航、稳定gutter、默认设置与背景URL修复；本轮经典滚动条电脑开发/生产各118项已实际通过，Git交付以所属main提交和实际origin/main引用核对；前次结果保留历史范围。

- 史册宿主观察实际stage至少60%可见并区分整应用/iframe局部焦点；七图/boot就绪且宿主授予会话资格后，延迟220ms调用原七页riffle并回序卷。独立session键 `nanfeng-lion:book-intro-seen:v1` 仅在真实开场启动或合法手动接管时写入，离页新iframe与正常同会话刷新不重播；未可视/加载失败不消费，存储不可用仅内存维持当前页面跨路由。离屏保留spring接续，手动取消开场；旧RAF/spring/捕获清理、离屏手动选择即时提交、中断拖拽回已提交页、动态reduce静态归位与盒内自然投影保持，原18层纸张/核心函数/SVG定义不变。来源：LionBookExperience、lionSketchbookDocument及本轮UI日志。

- 共用导航由NavigationIcon渲染用户原PNG，chapters.js的navigationIcons维护语义key/取景viewBox，assetPaths/media维护路径；透明留白取景保留原1254 RGBA与金白色，不加改色滤镜。SiteHeader的品牌胶囊为首页入口，NavigationSurface用React SVG/CSS提供两块独立红色切角、双细边与低对比云纹；章节右块只含结构/动作/神态/设置四项。site-nav-symbol将图案和普通sans短标题共同定位，当前红线位于图案与短标题之间；原首页图案退场后隐藏并移出键盘/读屏入口。

- 2026-10-14首页照片引擎由`features/home/CultureDepthGallery.jsx`以IntersectionObserver延迟动态载入`services/cultureDepthGallery.js`；React维护连续position、模4序号、原图片/图文/摄影许可与所有控制，Three只维护局部透明画布。服务使用现有Three0.160，不改依赖；原Codrops的全局wheel/body/debug和新版API没有引入。每张照片保持原比例，画面为平面纵深展示，不是照片深度重建。

- 同日轮播稳定性修复：service捕获scroll并始终监听window resize，容器RO/视口变化后仅复核已有hover，要求视口内且elementFromPoint命中canvas；blur/pointercancel/离开文档清状态，settled只释放失效hover。组件记录加载按钮的真实指针坐标，ready先清旧暂停，在同一DOM提交的layout effects中先setActive再一次性经syncPointer交给服务验证，避免延后旧坐标覆盖新输入；合法hover保留，失焦清待交接坐标。组件和服务各自清理监听，不增加常驻RAF/轮询；计时hook和设置默认值保持。

- 神态最新边界：ExpressionPage仍管理八态selection，新增内部overview/details模式；下半区、局部图及页脚不再渲染。右侧模式内容均来自原数据字段，中央独立按钮不与上下箭头嵌套；Enter/Space查看解读，返回/Escape恢复简介及焦点。select统一复位模式并取消点击回应，不更换路由或重绘资产。

- 2026-10-14章节分工更新：ChapterPage对action挂载独立ActionPage，对state挂载ExpressionPage。动作代码/样式隔离、actionClips四段数据与heritage时间轴保持；神态数据仍为lion-expressions.js，selection同步目录/狮头/右侧当前态，viewMode切换简介/详细。神态wheel仅绑主视觉，180ms静默+36px累计门槛限制切态，离页清理；原层叠/牌签与动态回退保持。

- 根 `index.html` 为唯一 HTML 入口，`src/main.jsx` 以 React `createRoot` 和 `StrictMode` 挂载 `App`。`App` 根据章节组合页面；史册沿用官方Sketchbook的sandbox srcDoc iframe嵌入，不增加独立网页入口。依赖由 `package.json`/`package-lock.json` 管理；源码目录为 `src/`。
- `features/home` 包含同页入场/循环视频状态与文化长页；`features/intro/IntroPage.jsx` 已删除。`model` 仅整体页，结构示意为同页状态；`chapters/ChapterPage` 挂载动作四段ActionPage及八态ExpressionPage。公共品牌、导航、首页播放回退、标题在components，动作原生媒体控制在features/action，媒体路径在config，图形服务在services/lionScene.js。
- `App`持有稳定site-shell/site-page与唯一SiteHeader；ChapterNav保留首页四章＋设置五项DOM，设置为开关。章节模式左品牌返回首页，右四项显示图案及普通短标题；原copy为连续动画保留DOM，最终opacity0/aria-hidden=true/pointer-events:none。旧页内导航、底部入口与EntryNavTools搜索/菜单已删除；BrandLockup仍共用原狮头/南风有狮，不恢复品牌辅助文案。
- React 管热点、三栏信息面板和加载状态；`ModelPage` 的 effect 挂载和释放 Three.js 服务，并把热点目标传给服务完成聚焦/复原。服务管理 renderer、controls、GLB载入、单一渲染循环内的相机补间与GPU资源，避免界面组件承担场景清理细节。
- 本地Hash现行路由为 `entry/model/action/state`；旧 `intro`→`entry`、`structure`→`model` 并以 `replaceState` 规范Hash，不增加历史项，非法地址和已删除评分回首页。白名单从 `chapters` 派生，`useChapterRoute` 同步 `hashchange` 与React状态，没有后端章节路由。

## 数据流与依赖

- 史册宿主在load/sync先发送intro-policy/enabled布尔资格；桥接introAllowed初始null，资格、ready、可视/前台均满足才运行原startIntro，并在真实introOn或合法手动输入后回报introConsumed。宿主经source/channel/index/状态校验收到消费标记后才保存session；重复StrictMode握手不终止同实例playing，retry换channel重新询问资格，减少动态静态跳过本身不消费。
