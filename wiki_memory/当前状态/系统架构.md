# 系统架构

## 模块职责与边界

- 2026-10-14首页照片引擎由`features/home/CultureDepthGallery.jsx`以IntersectionObserver延迟动态载入`services/cultureDepthGallery.js`；React维护连续position、模4序号、原图片/图文/摄影许可与所有控制，Three只维护局部透明画布。服务使用现有Three0.160，不改依赖；原Codrops的全局wheel/body/debug和新版API没有引入。每张照片保持原比例，画面为平面纵深展示，不是照片深度重建。

- 2026-10-14章节分工更新：`ChapterPage.jsx` 保留动作占位并按state路由挂载 `ExpressionPage.jsx`，八态数据集中 `src/data/lion-expressions.js`。单一selection同步目录、狮头层、右侧与下部说明；DOM原生非被动wheel仅绑主视觉并离页清理，180ms手势静默+36px累计门槛防连续跳态，不增加RAF/定时器。层叠/文字/牌签动画由CSS维护；减弱动态偏好沿用全局回退。新增狮头key经assetPaths/media适配BASE_URL，下方局部CSS取景复用同图；容器查询覆盖侧栏推开余宽。

- 根 `index.html` 为唯一 HTML 入口，`src/main.jsx` 以 React `createRoot` 和 `StrictMode` 挂载 `App`。`App` 根据章节组合页面，未使用 iframe 桥接。依赖由 `package.json`/`package-lock.json` 管理；源码目录为 `src/`。
- `features/home` 包含同页入场/循环视频状态与文化长页；`features/intro/IntroPage.jsx` 已删除。`model` 仅整体页，结构示意为同页状态；`chapters/ChapterPage` 保留动作媒体占位并为state挂载八态 `ExpressionPage`。公共品牌、导航、播放回退、标题在 `components`，页面数据与媒体在 `config`/`data`，图形服务在 `services/lionScene.js`。
- `App` 持有稳定的 `site-shell/site-page` 和唯一 `SiteHeader`；`ChapterNav` 从配置生成四章，第五项设置作为开关而非路由，顶部不显示章节数字。旧页内顶栏、底部入口与 `EntryNavTools` 搜索/菜单已删除。四页共用 `BrandLockup`，左侧小狮头与“南风有狮”居中且不再显示caption；原标题动效及首页探索云纹保留。
- React 管热点、三栏信息面板和加载状态；`ModelPage` 的 effect 挂载和释放 Three.js 服务，并把热点目标传给服务完成聚焦/复原。服务管理 renderer、controls、GLB载入、单一渲染循环内的相机补间与GPU资源，避免界面组件承担场景清理细节。
- 本地Hash现行路由为 `entry/model/action/state`；旧 `intro`→`entry`、`structure`→`model` 并以 `replaceState` 规范Hash，不增加历史项，非法地址和已删除评分回首页。白名单从 `chapters` 派生，`useChapterRoute` 同步 `hashchange` 与React状态，没有后端章节路由。

## 数据流与依赖

- `App`持有headerRef及`useNavigationMotion`，共用导航/CTA入口先捕获实际图标X，SiteHeader子级layout effect先完成目标布局，父级以WAAPI/FLIP水平补间；原生hash/history由useChapterRoute在同一回调中先捕获、再更新route。动画结束、相关参数/宽度变化、减少动态及卸载取消并清理；返回首页展开。图标恒红，compact只显示原SVG，当前icon::after红线；设置常挂组件保留分类，四tab页面及固定footer共用旧存储key/version2，新四字段补默认。来源：`App.jsx`、导航动画模块、`SiteHeader.jsx`、`DeveloperSettingsPanel.jsx`，本轮功能日志。

- `SiteHeader` 的 `useNavigationLayout` 分别测量标题和辅助文字的真实Range字宽，按各自请求字号加权，再用共同scale分配5项宽度，保持完整单行和字号比例。观察page宽、壳参数style、字体完成和窗口resize，单RAF/active保护及清理；独立实际--site-header-height同步正文/拖动，保存请求保持。窄宽品牌独立行，电脑导航完整单行；图标受高度预算限制，64px顶栏与实际边界一致。首页书法assetPaths/media→HomePage装饰img，aria-label和文化scroll保持；题图/按钮均值宽度布局实现共同中线。2026-10-14核实来源：`src/hooks/useNavigationLayout.js`、`src/styles/navigation.css`。

- App用model/action/state映射 `media.modelBackground/actionBackground/stateBackground` 到site-shell的固定cover背景；各stage透明，页脚、顶栏后方和推开侧栏后的底板共用对应图。首页背景仍为视频，入口/路由/唯一SiteHeader不改变。图片集中assetPaths/media管理，实际PNG虽源扩展名jpg，部署用正确png且不重新编码；出处/尺寸/哈希见背景来源说明。
- 2026-10-14动作/神态章节容器保持透明，覆盖原图的整页米黄渐变与暖黄色卡片底已去除；动作媒体框和白色局部信息区保留，神态下部为白色局部说明区。背景图及cover/center/fixed配置保持。远端仅去全页遮罩时的桌面像素对照证据见 [[日志/UI修改/2026-10-14-动作神态移除全页黄色遮罩.md]]；当前合并样式仍待整体验证。
- 2026-10-12背景适配时旧model伪元素祥云/暗角删除，裸露状态文字改深墨，中央只加字影以防红墨覆盖文字，不加内框/地面；两侧档案卡保留。当时动作/神态局部覆盖墨色变量、透明旧黑底，正文深褐，序号/节点小浅底提高可读性；不改模型服务、内容占位或全局导航字体/玻璃参数。

- `useDeveloperSettings` 校验并保存 `nanfeng-lion:developer-settings:v1`，打开状态始终默认false。`navigationTypographyVersion: 2` 保持，未升级的旧20一次提升到26，已为v2的20保留；缺失新字段时补`helperFontSize:18`，既有参数不覆盖。标题`navFontSize`默认26、范围14–28，辅助`helperFontSize`默认18、范围10–28；`App`传递两个CSS变量，默认值、校验、实时修改、保存和复原使用同一状态。材质通过各自背景alpha/filter生效，文字不随容器淡出；标题与辅助文字共用本地WOFF字体、字号独立，字体/OFL经集中media路径部署。2026-10-14核实来源：`src/features/developer-settings/useDeveloperSettings.js`、`src/features/developer-settings/DeveloperSettingsPanel.jsx`、`src/App.jsx`、`src/styles/navigation.css`。
- 设置侧栏固定贴右全高，内部滚动；`useSettingsPanelLayout` 观察实际宽度和窗口resize，剩余页面至少900px才推开，否则保留推开偏好并临时覆盖。首页视频/模型背景延伸至顶栏后方；导航和模型按页面容器宽度适配，参数变化不更换video/canvas。
- `ResizeHandle` 覆盖整条顶栏底边/侧栏左边，悬停显示中央grip。pointer capture加窗口兜底、单一RAF实时预览，松手才提交存储；Escape、pointercancel、capture丢失、blur/pagehide/hidden与卸载恢复初值并清监听、RAF、capture和全局拖动样式。支持方向键/Shift/Home/End和双击默认尺寸，关闭面板返回设置入口焦点。

- 导航点击 → Hash/React route → `App`选页。首页 `useEntryPlayback` 以 `nanfeng-lion:intro-seen:v1` 记录session：首次入场 → 结束/跳过/错误继续 → 用户循环视频，全程保持 `entry`；返回或刷新不自动重复，显式重播重新挂载入场播放器。存储不可用时有当前页面内的回退，`VideoStage` 管播放阻止/错误提示及离页暂停。
- `HomeCulture` 从 `home-culture.js` 读取四组文化图文与摄影许可，从 `media`取图片。`useCultureCarousel`维持可正负连续position与最短主题跳转；自动播放需可视/前台且未悬停/聚焦/暂停/减弱动态，辅助朗读使用有效自动播放状态。`cultureDepthGallery`复用8个虚拟照片槽、间距5、45°透视和约780ms镜头推进，局部鼠标视差/32点短尾，DPR≤1.75；稳定后停止RAF。ResizeObserver适配电脑余宽，离页/失败释放监听、观察器、RAF及GPU，晚到纹理也释放。减弱动态使用静态图并在恢复时重建canvas，WebGL/纹理/contextlost回退DOM照片；滚轮不被拦截。HomePage探索更多进入model，底部文化入口继续滚到`#homeCulture`，未新增章节。完整MIT许可经assetPaths/media登记进入dist。
- `ModelPage.showGuide` 在整体页控制 `structureLayer` 的可见性；“查看结构示意/关闭结构示意”和复原按钮不导航，canvas与右侧结构工艺卡保持挂载。复原关闭示意并重置视角，结构滑杆仍是合并网格的语义示意。
- 模型页通过 `React.lazy` 载入，effect再动态导入 `lionScene.js`；服务使用本地npm Three.js、OrbitControls和GLTFLoader。服务 `fetch` 下载GLB，`parseAsync` 解析，成功后回报 `ready`，失败保持预览和重试；`focusOn` 与 `resetView` 复用同一个 render loop，不创建第二套 RAF。
- 2026-10-11全页画布修正：`sceneContainer` 为 `modelStage` 直接子级，透明canvas覆盖整页，`pointer-events: none`；中央 `scene-interaction` 独立承接OrbitControls，热点、回退与控件继续由React维护。`sceneFrame` 填充中央列并允许溢出，取消16:9与裁切；标题、说明和控件绝对定位，中央列桌面高度为 `max(680px, 100svh - 240px)`，900px以下为 `max(560px, 100svh - 230px)`，不随档案卡内容伸高。
- 渲染与交互尺寸分开：`camera.setViewOffset` 用中央交互区域的宽高定义构图，再用相对全页画布的负偏移扩展可见投影，避免中央矩形成为绘制边界。`ResizeObserver` 观察画布容器、交互层和页头，resize同时更新投影、画布尺寸和DPR；DPR上限2，并按 `MAX_RENDERBUFFER_SIZE` 限制绘制缓冲区。renderer继续 `alpha: true` 和透明清屏，scene只保留模型与照明，无地面；退出时仍取消单一RAF、下载和观察器并释放图形资源。
- 媒体原路径来自 `assetPaths.js`，`media.js` 加 Vite `BASE_URL`；热点JSON直接导入 `ModelPage`。本次读取现用GLB的JSON头，确认1个mesh/1个node，mesh名为 `LionHead_Overall_MergedMesh`；结构层是页面语义示意，没有真实独立部件拆分。
- 离开模型页 → `AbortController.abort()` / `dispose()`；服务取消fetch和动画帧、断开观察器、移除监听、释放controls/纹理/材质/几何/renderer。`WeakMap` 保护容器所有权，解析后若已取消也释放模型。详见 [[知识/前端与三维生命周期.md|生命周期知识]]；源码清理存在不等于已量化无内存泄漏。

## 运行与部署

- Vite配置 `base: './'`、`publicDir: 'source/public'`、开发5173/预览4173、`outDir: 'dist'`、`emptyOutDir: true`。`source/public` 静态文件原样进入dist，非public创作文件不随构建发布。
- npm网页启动与 `scripts/` 离线模型/PSD制作工具分离；Python或Blender不是 `npm run dev` 的启动前提。Windows `runStart.cmd` 切换到脚本目录后调用同一 `npm run dev -- --open`，不构成第二套网页入口。
- `src/`应用、`tests/`验证、`scripts/`辅助工具、`docs/`开发说明、`source/`资源、根 `wiki_memory/`工程记忆互有边界，只有一份当前事实源。
- 本地预览不是正式部署。托管平台、域名、发布方式尚未决定；Hash路由通常不要求章节路径回退，实际部署基址和WebGL环境仍需目标环境验收。
