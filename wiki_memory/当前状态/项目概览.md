# 项目概览

## 项目目标与阶段

- 《南风有狮》醒狮信息可视化网页，面向醒狮视频入口、三维展示与六章信息浏览。既有用户目标为 React + Vite、根目录 `npm run dev`、统一 `source/` 资源管理；本次追加要求为根目录标准工程记忆和 README 导航。
- 当前工作区已具备 React/Vite 单页结构：首页循环视频、图片标题、入场视频、整体与结构模型页已接线。动作、神态、评分由 `chapterContent` 提供占位文案，不能列为内容成品。证据：`src/App.jsx`、`src/config/chapters.js`。
- 工程处于“本地迁移已落盘，内容扩展与正式发布待定”阶段。此前迁移测试记录位于原迁移日志；本次任务整改记忆与引用，未再次执行网页构建或浏览器回归。

## 核心入口

- 启动：根目录 `npm ci` 后 `npm run dev`；配置地址 `http://127.0.0.1:5173/`。构建命令 `npm run build` 输出 `dist/`，`npm run preview` 默认4173。这是已核实的命令配置，不代表本次执行结果。证据：`package.json`、`vite.config.js`。
- 源码链：`index.html` → `src/main.jsx` → `src/App.jsx`；六章配置 `src/config/chapters.js`，Hash 状态由 `src/hooks/useChapterRoute.js` 管理。
- 资源分类与运行边界：`source/README.md`；只有 `source/public/` 是 Vite 静态资产目录，应用路径在 `src/config/assetPaths.js` 与 `media.js`。
- 记忆：根 `wiki_memory/README.md` 统一导航，`wiki_memory/AGENTS.md` 为协议，`.memory.json` 固定 `standard`。任务恢复先读本页、当前约束和当前待办。
