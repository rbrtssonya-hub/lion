# 项目概览

## 项目目标与阶段

“狮相万象 / THE LION ATLAS”是基于用户真实醒狮模型的桌面文化交互展示。重点是点击部位后进入图文信息可视化，模型保持整体。六章为眉目、额冠、鬃须、织锦、云边、口齿。[实现](../../src/components/AtlasExperience.jsx)

当前产品基线已实现：完整模型首页、六个艺术图入口、相机聚焦、同构图主图替换模型、右侧 GSAP 文化标题、编号文化图解与真实形态数据。三组共十八张图片分别承担入口、主图与文化示意；左上角图标已移除。[现有验收](../../artifacts/enrichment/VERIFICATION.md)

本轮配置标准工程记忆与本地 Git，并将每轮修改提交要求接入根指令；本轮没有新增产品功能或修改模型。

## 核心入口

- `AGENTS.md`：生效项目约束与每轮本地提交要求；记忆维护协议在 `wiki_memory/AGENTS.md`。
- `src/main.jsx` → `src/App.jsx` → `src/components/AtlasExperience.jsx`：当前入口；样式为 `src/experience.css`。
- `src/components/CulturalPanel.jsx`、`src/content/culture.js`：文化图解、分项、资料及数据页。
- `src/model/LionWorld.js`、`PartRegistry.js`：模型、相机与真实几何分析。
- `README.md`、`VISUALIZATION_DESIGN.md`、`MODEL_AUDIT.md`：运行、设计与源模型审计。
- `启动网页.cmd` 或 `npm run dev` 启动；`npm run build` 构建。详见系统架构页。

## 工作区背景

工程根：`C:/Users/Administrator/Desktop/炫技5`；Windows / PowerShell。2026-10-26 配置时确认原先没有 Git 仓库，本轮执行 `git init -b main`，无已配置远程或 upstream。

本轮交付包含现有项目基线及记忆。提交号用 `git log -1 --oneline` 定位；接续重新检查 `git status --short`、`git branch --show-current`，不能把此快照当实时状态。`node_modules/`、`dist/` 等沿用忽略规则，源码、原模型、网页资源和验证资料保留跟踪。
