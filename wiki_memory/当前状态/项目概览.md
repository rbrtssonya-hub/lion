- 《南风有狮》醒狮信息可视化网页，面向醒狮视频入口、三维展示与六章信息浏览。既有用户目标为 React + Vite、根目录 `npm run dev`、统一 `source/` 资源管理和根目录standard记忆；本次要求按真实工程同步GitHub并明确提交 `runStart.cmd`。

- 工程处于“React/Vite 迁移已随 `c1a359b` 提交推送，内容扩展与正式发布待定”阶段。本次重跑资产、构建和开发/生产预览浏览器回归，具体结果见同步交付日志；仓库推送不等于网站正式部署。

## 核心入口

- 启动：根目录 `npm ci` 后 `npm run dev`；配置地址 `http://127.0.0.1:5173/`。Windows 可双击 `runStart.cmd`，脚本用 `%~dp0` 定位工程再运行 `npm run dev -- --open`。构建命令 `npm run build` 输出 `dist/`，`npm run preview` 默认4173。证据：`package.json`、`vite.config.js`、`runStart.cmd`。
- 源码链：`index.html` → `src/main.jsx` → `src/App.jsx`；六章配置 `src/config/chapters.js`，Hash 状态由 `src/hooks/useChapterRoute.js` 管理。
- 资源分类与运行边界：`source/README.md`；只有 `source/public/` 是 Vite 静态资产目录，应用路径在 `src/config/assetPaths.js` 与 `media.js`。
- 记忆：根 `wiki_memory/README.md` 统一导航，`wiki_memory/AGENTS.md` 为协议，`.memory.json` 固定 `standard`。任务恢复先读本页、当前约束和当前待办。
