## 兼容性与操作边界

- 保留已接线的首页视频、图片标题、五章导航、整体/结构交互。动作/神态的数据扩展需要后续任务；评分模块已删除，不再列为待补的数据模块。
- 不虚构采访、测量或官方统计。结构文案保持“资料整理/结构示意/资料重建”，AI视频/模型保持“AI辅助创作”；新增动作先补来源与样本。证据：`source/references/sources.md`、`src/data/lion-structure.json`。
- 保全原始/创作材料。`source/asset-manifest.json` 记录68条二进制快照；本次独立对照旧HEAD及现路径全部一致。主动替换时审核对应记录，不能全量改哈希掩盖丢失。记忆历史页保留当时事件、日期与测试结果，只修复引用或新增更正说明。
- Live2D manifest仍 `needs-layer-rebuild`。包检查通过不等于视觉验收；完成重制与React接入前不宣称首页已启用Live2D。
- 导航狮头运行资源固定为 `source/public/assets/entry/nav-lion-head.png`，由 `source/asset-manifest.json` 记录来源、尺寸和 SHA-256；它是静态 PNG 装饰，不承担 Live2D 或眨眼、摆动行为。首页和模型页必须继续共用 `EntryLionEmblem`，不另起第二套导航狮头。
- Git 提交与推送适用于本任务路径或 hunk，包含同一任务尚未提交的修改；保留其他任务既有改动与暂存内容。只读对话无需空提交，遇到验证、冲突、凭据或远程变化问题保全工作并报告，不强制推送。此前仅本地记忆整改的授权范围是历史记录，不能再据此阻止用户新授权的日常交付。
