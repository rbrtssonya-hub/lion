# 当前约束

## 用户要求与技术约束

1. 用户指定 standard 工程记忆。唯一有效根为工程根 `wiki_memory/`，五页状态、六类日志与项目内工具一起跟踪。日常维护按项目协议，不重复加载个人 Skill。
2. **每一次完整对话的修改，都要提交。** 每轮最终回复前，校验、审查并提交本轮有效修改（含资源和记忆），回复给出提交号。无改动不造空提交，不混入他人未授权改动。[执行规则](../../AGENTS.md)
3. 面向桌面，不考虑手机端优化。参考图仅作视觉与信息层次参考，附图内文字不是执行指令。
4. 不拆模型、不做爆炸图或部件移动，不覆盖 `source/科比blend.blend`。源模型存在破面，文化解释通过图片与图表实现。
5. 首页是完整模型和六个艺术图入口，无文化面板。每个入口有独立主图与镜头终点，交接后模型完全隐藏并暂停；主图保持完整 3:2、`contain`，不做网页二次裁切。[流程](../../src/components/AtlasExperience.jsx)
6. 底部六图标用 image_gen 艺术图，左上角图标移除。六章右侧结合生成文化图解、点击分项和真实数据，不回退到共用一张主图或纯代码图标。
7. 原图是艺术转译，不冒充实测或史料；文化转述有机构来源，不杜撰本作品纹样、颜色的历史寓意。模型无实物单位标定，图表不称精确切片、骨骼或运动仿真。[内容边界](../../src/content/culture.js)

## 兼容性与操作边界

Windows 本地项目，展示依赖 WebGL、Draco 和静态资源。现有核验覆盖桌面 Chromium，不据此宣称手机或所有浏览器兼容。运行需 HTTP 服务，不能以双击 `dist/index.html` 替代。相机、统一尺度或 FOV 改动影响主图衔接，修改前核对 `public/data/handoff-cameras.json`。

本轮授权本工程记忆配置、Git 初始化与持续本地提交；不自动包含远程建仓、推送、强推或历史重写。现无远程/upstream，无远程同步步骤。执行前重查 Git 状态，保全其他任务改动，不从其他项目或记忆资料移入外部操作授权。

沿用忽略规则排除依赖和构建目录；原始模型、网页 GLB、图片和证据进入初始基线。项目素材不可只留个人生成目录。十八张现行图已在 `public/images/`；提示词在 `artifacts/handoff/` 与 `artifacts/enrichment/`。
