# 当前约束

## 用户要求与技术约束

- 2026-10-09 首页UI任务要求：主标题“南风有狮”仅允许修改 `font-size`，其字体、字形、颜色、位置、两行排版、容器及其他样式必须保留；媒体、醒狮构图和原文案也保留。当前主标题为PNG而非字体文本，字号不会改变图片；已保持原标题，图片缩放尚未得到额外授权。证据：`src/components/TitleMotionLayer.jsx`、`src/styles/home.css`、[[日志/UI修改/2026-10-09-首页参考图视觉重构.md|首页UI日志]]。
- 网页使用React + Vite，根目录 `npm run dev` 为开发入口，运行源码集中 `src/`。根项目指令要求不恢复旧 `site/`、`react/`、`output/` 或第二套入口；Windows `runStart.cmd` 是调用同一Vite入口的启动脚本，用户明确要求纳入本次提交。
- 图片、视频、模型、PSD/Cubism、审查图与设计方案统一 `source/`；仅部署资产进入 `source/public/assets/`。开发说明在 `docs/`，辅助工具在 `scripts/`；工程记忆作为用户本次明确指定的例外，必须直接位于根 `wiki_memory/`。
- 用户选择 `standard`：五页当前状态实质记录目标/架构/约束/任务/问题，重要结论有证据与未核实范围。README统一导航、AGENTS保存协议，取消 `入口.md`；保留中文专题文件和目录。ADR/知识按实际需要创建，不为填目录编造内容。
- standard日志必须按功能添加、UI修改、Bug处理、工程讨论、测试验证、工程维护六目录归档，`kind` 与目录一致；实际目录和映射见 [日志分类](../README.md#日志分类)。空分类以 `.gitkeep` 保留，历史迁移仅修必要引用，不重写当时正文。
- 用户于 2026-10-09 对 lion 明确持续授权：每次完整对话涉及项目文件修改时，最终回复前同步记忆、执行适用验证、审查 diff、提交本次任务改动并推送已配置的 GitHub upstream，无需再次确认。根 `AGENTS.md` 为执行依据，选择记录见 [[决策/ADR-005-完整对话修改提交与推送.md|ADR-005]]。
- 包管理为npm与 `package-lock.json`；Node版本遵循 `package.json`。Vite生产输出 `dist/`，不得覆盖源码和资源。

## 兼容性与操作边界

- 保留已接线的首页视频、图片标题、六章导航、整体/结构页视觉与交互。动作/神态/评分的数据扩展需要后续任务；本次交付此前现用迁移并修复启动脚本目录定位，不扩展章节或重制资产。
- 不虚构采访、测量或官方统计。结构文案保持“资料整理/结构示意/资料重建”，AI视频/模型保持“AI辅助创作”；新增动作先补来源与样本，评分注明规则年份。证据：`source/references/sources.md`、`src/data/lion-structure.json`。
- 保全原始/创作材料。`source/asset-manifest.json` 记录68条二进制快照；本次独立对照旧HEAD及现路径全部一致。主动替换时审核对应记录，不能全量改哈希掩盖丢失。记忆历史页保留当时事件、日期与测试结果，只修复引用或新增更正说明。
- Live2D manifest仍 `needs-layer-rebuild`。包检查通过不等于视觉验收；完成重制与React接入前不宣称首页已启用Live2D。
- Git 提交与推送适用于本任务路径或 hunk，包含同一任务尚未提交的修改；保留其他任务既有改动与暂存内容。只读对话无需空提交，遇到验证、冲突、凭据或远程变化问题保全工作并报告，不强制推送。此前仅本地记忆整改的授权范围是历史记录，不能再据此阻止用户新授权的日常交付。
