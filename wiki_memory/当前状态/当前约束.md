# 当前约束

## 用户要求与技术约束

- 2026-10-12最新用户要求：附件第一张用于狮头与结构/model，第二张用于动作/action，第三张用于神态/state，所有页共用首页顶栏。这替代此前模型朱红渐变底与动作神态黑底的样式；三图原字节接入，首页视频和已认可的顶栏/设置参数保持。来源按附件顺序记录，下载文件名中的鉴权字符串不写入工程资料。

- 本轮用户明确先看UI、通过后再完整测试/记忆/提交推送；最终答复“UI 通过，继续验证并提交推送”后，门禁已满足。本要求属于本轮顺序，不扩大为所有后续任务的重复批准流程。
- 导航序号、标题、右侧辅助文案同毛笔字体和字号；默认26px，1920桌面24px，较窄页面自适应。序号/图标纯白，辅助白色半透明；字号和辅助透明度可调。Agent依据笔锋选择演示秋鸿楷的OFL子集，用户认可最终UI；附件为位图，未确认是原图字体，不声称精确同款。字体来源/许可/生成方法保留在source。
- 设置默认折叠、为顶栏第五项，右侧占满视口高度；顶栏和侧栏独立可调透明度/模糊，透明度只作用材质。可推开页面，空间不足暂时覆盖，偏好不丢失。整条边界悬停反馈位于中心，并支持自行拖动尺寸、取消/复原和键盘操作。只读研究用户参考工程 `E:/Software Development/WebPage`，未修改或提交该工程。

- 2026-10-12现行顶栏为首页/狮头与结构/动作/神态加第五项设置，旧右上牌签、搜索/菜单及底部导航按用户要求删除。四路由仍是entry/model/action/state，旧intro/structure分别兼容entry/model，评分/未知链接回首页。四页品牌共享左侧Logo与“南风有狮”，居中、左侧留白可调，删除“广府醒狮·数字档案”。
- 首页首次session播放入场，结束或跳过后切入用户指定循环视频，返回/刷新不自动重复，允许显式重播。首屏保留原标题和动效，首屏之后直接阅读四组醒狮文化图文，CTA只向下滚动。文化区使用真实有CC许可的摄影，保留作者、具体文件来源、许可链接，不将海外活动图片称作广东本地活动，不把狮头实景称作制作过程；依据为文化来源说明。
- 整体模型保留用户指定的整页背景、透明WebGL画布及原旋转/缩放/聚焦/重置，禁止恢复中央矩形裁切、独立地面或装饰内场景。结构工艺卡常驻，同页showGuide仅控制结构示意，不伪造可分离部件或新增结构导航；现行宣纸图替代此前朱红渐变。

- 保留当前首页内入场/循环播放、原标题、四章导航和整体页交互；动作/神态数据扩展需后续任务，评分已删除。旧intro/structure链接必须兼容，但不恢复独立页面。
