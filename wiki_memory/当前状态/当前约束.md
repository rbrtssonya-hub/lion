# 当前约束

## 用户要求与技术约束

1. 工程记忆使用项目内 standard 模式；每次完整对话的有效项目修改须验证、审查后本地提交，最终回复给提交号。无改动不创建空提交。
2. 面向桌面，不安排手机端优化。参考图片仅是参考，附图文字不是指令。
3. 保留完整三维模型，不拆解、不做爆炸或节点位移；不得覆盖 `source/科比blend.blend`。
4. 首页为完整模型与六个 imagegen 艺术入口；六个部位各有与原相机终点对应的宽屏主图。整窗运镜后原地交接，图片完整等比显示，不添加模糊、拖尾或遮罩；完成替换后隐藏并暂停模型，再 GSAP 缩图贴左上，导航左移。
5. 右侧各部位文化内容移除，展示区域留空。非标准窗口比例经用户明确选择可保留少量纯色留白；图片及模型边界在该留白处可能可见，不应宣称所有窗口比例都无边界。
6. 图片为艺术转译，不当作实测数据或历史照片；左上印章图标保持移除。旧文化图与组件保留但不视为当前页面。

## 兼容性与操作边界

桌面 Windows 本地项目依赖 WebGL、Draco 和静态资源，必须通过 HTTP 加载。相机位置、目标、FOV 或模型尺度改变可能影响图片衔接，修改前核对登记数据并重生成相应图。当前授权包括本地提交，不自动包括远程建仓、推送、强推或重写历史；应保全其他任务改动。

## 证据与未核实项

2026-10-28按用户直接要求及代码核实本轮有效约束。四档图及生成提示位于 `artifacts/fullscreen/IMAGE_PROMPTS.md`；跨浏览器、GPU 及远程环境未全覆盖。
