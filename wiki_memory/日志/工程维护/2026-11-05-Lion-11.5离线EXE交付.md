## 实测

- Windows 11 x64、Node 24.16.0/npm 12.0.1 下执行 `npm test` 154/154、打包选项及本地服务测试 3/3。`build-bundled.mjs` 的隔离 Vite 生产构建通过（995 模块，保留大于 500 kB 的 Three chunk 提示）。首次打包工具下载遇 HTTP 504，复用同 revision 且清单逐项核对的构建重试成功。278 个网页文件中含 259 个公共资产。10 个 MP4 均完成解码，只有首页循环视频的发布副本由 HEVC 转为 H.264/AAC。
- 最终 EXE 的 `verify-delivery.mjs` 13/13。使用仅有 System32 的 PATH 启动成品并连接其 Chromium 152.0.7977.167、Electron 44.9.1 和 Node 24.22.0，核对 355 个内核运行清单条目、清单自身、网页文件、本地 HTTP 字节和 10 个 MP4 的 Range。实际检查入场、首页循环、七页书册、观形 WebGL 和毛发、舞章两处预览、八态纵深图鉴、展厅四视频、三级地图、小醒本地回答和固定录音播放、外部请求拒绝与退出回收。前一次成品验收的书册点击与首页平滑滚动发生竞态，等待入口导航可见再翻页后在同一 EXE 通过。
- `verify-bundled-gui.ps1` 普通启动通过。前台窗口截图为 2560×1440，调试端口关闭。正常关窗后 EXE 和包装器退出码均为 0，所属进程和本地服务均退出。逐张查看了最终 9 张验收截图。
- `finalize-delivery.ps1` 对 ZIP 的 7 个文件逐项解压读取并比对解压目录的大小和 SHA-256。验收输出在本地忽略目录 `tmp/lion-11.5-qa/`。
- 工程记忆 `check --require-ready` 检查 180 页，0 个错误，7 条历史源码路径提示。

EXE 面向 Windows 10/11 x64，浏览器内核、网页运行文件及固定章节讲解随包携带。本次只实测当前 Windows 11 电脑，未覆盖其他机器、软件渲染兼容模式或完整 Playwright 套件。资料原文及 DeepSeek 实时问答需联网，实时问答还需配置网关，动态语音需独立 GPT-SoVITS 服务。成品未签名。
