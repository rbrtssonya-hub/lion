# 传章北京标点位置校准

北京市政府概况页给出北京约北纬 39°56′、东经 116°20′。地图数据由原 `[116.40, 39.90]` 改为近似 `[116.33, 39.93]`。按中国 Blender 图幅现有田阳、泉州、香港锚点校准，官方坐标投影到 1000×650 画幅约为 `[638, 210]`；标点从 `[637, 212]` 调整为 `[638, 210]`。这是一项基于当前 Blender 图幅与现有锚点的近似像素投影，不代表测绘精度。

地图城市圆点是地理锚点；邮票按钮仍使用引导线避让布局。来源及坐标回归测试固定市政府经纬度与中国图幅标点位置，投影像素容差为 1.5px。

验证：`node --test tests/assets/spread-data.test.mjs` 4/4；Edge 通道 Playwright `tests/e2e/spread-map-render.spec.js` 4/4；`npm run build` 383 个模块成功，仍有既有主包体积提示。未部署网页。
