# 首页轮播与三章界面改版

## 目标

执行用户确认的首页文化轮播、顶部导航清理、Figma三章设计和网页视觉同步；保留已有首页视频、整体模型和章节路由。

## 结果

- 首页四组 homeCultureStories 改为单项展示的文化档案轮播，图片、标题、正文、注释、摄影署名和档案来源同步切换。
- 轮播默认6秒，支持上一项、下一项、主题点、播放/暂停、悬停/键盘焦点暂停、页面后台暂停和减少动态效果手动模式。
- 新增低对比 lion-culture-pattern.svg 纹理并纳入运行资源及资产清单。
- ChapterNav 删除导航数字，保留五个文字入口、图标、路由、当前高亮、设置入口和手机回退。
- 在 Figma 工作区创建《南风有狮 · 广府醒狮数字展厅》，包含四个 1920×1080 可编辑页面。结构页说明当前 GLB 是合并网格；动作页使用“动作视频待接入”；神态页保留定性观察节点。
- 动作与神态网页按 Figma视觉同步为暖米纸三栏档案布局；没有复用入场视频，也没有编写未经样本支持的量化资料。

## 验证

- npm test：9项通过。
- npm run build：成功；保留 Three.js chunk 超过500kB的既有提示。
- PLAYWRIGHT_CHANNEL=chrome npx playwright test：开发环境34/34通过。
- PLAYWRIGHT_CHANNEL=chrome npx playwright test --config playwright.preview.config.js：生产预览34/34通过。
- Figma结构读取确认四个页面和四个1920×1080画板存在；四页截图复核通过，标题定位缺陷修正后再次复核三章截图。

## 未完成与恢复

- 动作专用视频、真实神态样本、结构真实分件、Live2D重制、真实设备性能和正式托管仍未完成。
- 后续补齐媒体后，先更新来源和数据说明，再接入当前 Figma 页面预留区域；不要把入场视频当作动作分析视频。
