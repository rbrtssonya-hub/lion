# 书册人物参数改为上下间距

## 更正与实现

用户纠正此前“站立点间距”应为书页与下方人物时间线之间的上下距离。此前新增的七站左右展开参数不符合意图，现已移除，改为 `bookGuideVerticalSpacing`：默认32px、范围0–80px，控制书页舞台与下方时间线所在底栏之间的纵向留白。人物比例继续保持默认150%、范围100%–250%，脚底与年代站台关系不变。

新参数在“开发者参数 → 首页 → 书册 → 书册下方人物”公开，接入原有实时预览、保存、恢复、导出设置流。没有更改图片、模型或其他运行资产。
