# 书册人物比例上限与站立点间距

## 目标与实现

沿用原人物默认150%，把可调范围提高到100%–250%；常规96px和短窗口80px基准继续按比例换算，并补偿垂直偏移以保持脚底对齐。新增`bookGuideSpacing`站立点间距设置，默认115%、范围100%–120%，按七个年代站点分别向时间线两侧展开；轨道端点同步移动。书册参数即时预览、持久化、恢复和导出均由既有设置机制处理。人物随当前站位移动；调整间距后重测站点，减少动态时使用同一偏移。

## 验证

Windows PowerShell / Chrome。`npm run build` 成功，379模块；保留现有`lionLightingSettings` 648.67kB超过500kB提示。独立生产预览端口4205的人物参数专测1/1通过：人物150%/250%分别144px/240px，短窗口250%为200px；脚底偏移在调整尺寸和减少动态时均稳定。间距115%→120%后七站距离增加，人物与选中台阶仍居中；两项设置保存为125/120。

相同4205回归中的七站综合项已通过平台/轨道的水平与垂直几何断言，但后续点击“传播”按钮时该按钮仍为disabled，60秒超时，整项不记通过。为使平台中心与2px轨道中线共线，普通/短窗口轨道定位各上移1px（67→66px，54→53px）。另在生产预览端口4202运行1920×1080与1366×768书页回归：1920项因`.lion-book-reading`底边1203px超出该次视口预期1081px而失败，1366项运行60秒超时。垂直阅读区布局没有纳入本次改动，以上广域回归结果仍需后续基线复核；本日志不把它们记作通过。`git diff --check`通过；没有运行资源检查，因为本次未改运行资源。
