# 导航栏狮头替换

## 目标与实现

- 从 `F:/数媒竞赛/醒狮素材/UI狮头.png` 提取狮头主体，去除白色背景与标注框，生成 `source/public/assets/entry/nav-lion-head.png`。
- 新资源为 `1859×1976` 的 RGBA PNG，保留 12px 透明安全边距；通过 `assetPaths.navLion` 和 `media.navLion` 统一接入。
- `EntryLionEmblem` 从内联 SVG 改为透明 PNG，首页和模型页继续共用 `ChapterNav` 的 entry 导航；章节、搜索、菜单、工具按钮和移动端回退逻辑保持不变。
- 仅调整图片的等比例容器显示方式，未新增狮头动效，也未修改整体 GLB、首页媒体或章节内容。

## 实际验证

- `npm test`：7项通过，包含资源清单哈希、RGBA PNG 和公共资源路径检查。
- `npm run build`：成功；保留既有 Three.js 分包体积提示。
- Chrome 通道开发回归：`npm run test:e2e`，10项通过。
- Chrome 通道生产预览回归：`npm run test:e2e:preview`，10项通过。
- 额外在 1920×1080 和 2560×1440 截图检查首页与模型页：狮头完整显示、未遮挡“入场”、未出现白色背景方块，也未溢出导航工具区域。

## 范围边界

本轮只替换导航装饰狮头；未把该静态图片扩展为 Live2D，也未改动页面中的醒狮视频、整体模型和章节跳转行为。
