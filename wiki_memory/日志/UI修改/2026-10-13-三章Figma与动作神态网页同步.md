# 三章 Figma 与动作神态网页同步

## 目标

完成《南风有狮 · 广府醒狮数字展厅》Figma 三章高保真框架，并将动作、神态两章同步为中央主视觉与左右信息面板的三栏网页布局；保留结构页现有真实 GLB、热点、旋转缩放和合并网格真实性说明。

## 结果

- Figma 文件 `南风有狮 · 广府醒狮数字展厅` 已创建，文件 key 为 `csAMJswRKrFo1y6iU45FBL`。
- Figma 页面 `Design Tokens`、`01 结构`、`02 动作`、`03 神态` 已存在；三个章节画面均为 1920×1080 可编辑节点。
- 逐页切换并验证：`01 结构` root `8:2` 有70个后代节点/37个文字节点；`02 动作` root `11:2` 有44个后代节点/28个文字节点；`03 神态` root `12:2` 有55个后代节点/29个文字节点。结构页关键热点和合并网格说明、动作页待接入文案与入场/展开/收势、神态页注视/警觉/唤醒及资料状态均存在。
- 动作网页改为三栏档案布局：左侧动作说明，中央明确的“动作视频待接入”占位和状态，右侧定性时间轴；不复用入场视频，不填写未经样本核对的持续时间、频次或评分。
- 动作网页收尾补齐媒体内层画面框和底部状态控制条；桌面时间轴横向排列为“入场 / 展开 / 收势”，手机宽度回到纵向节点，保持信息可读和不横向溢出。
- 神态网页改为三栏观察布局：左侧局部示意，中央眉眼嘴观察区，右侧注视/警觉/唤醒标签；保留等待真实图片/视频样本校核的资料状态，不生成量化结论。
- 结构页保持现有 Three.js 模型交互与合并网格边界，未伪造真实独立分件。
