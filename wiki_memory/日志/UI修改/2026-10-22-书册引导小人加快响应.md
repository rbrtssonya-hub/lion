# 书册引导小人加快响应

基于 `main@9046c7d`，书下横向引导小人的移动时长从 650ms 调整到 400ms，移动序列按 30fps 绘制，使 12 帧步态与一个移动周期相配。收到新目标时将首帧计时起点设为当前高精度时间，减少一帧等待；快速反向选择仍从最近一次绘制位置接续。复用同一 hook 的纵向首页导航保留 650ms。

验证：Windows PowerShell / Node v24.16.0 / npm 12.0.1 执行 `npm run build`，Vite 7.1.9 转换 345 个模块并成功输出；Three.js 538.05kB chunk 仍提示超过 500kB。未运行浏览器回归。
