# 模型页首页色调背景

## 目标与实现

用户提供的截图显示整体/结构模型页仍使用黑绿色大底，与首页的朱红醒狮视觉不一致。本轮保留模型、热点、章节导航、右侧信息和结构交互，只调整背景体系：

- `.model-stage` 改为首页同源的 `#68170f` 深朱红、暖红和暗红渐变，并加入低强度暖金光晕。
- `.scene-frame` 改为朱红展示框，保留展示层次和模型对比度。
- 结构控制条、载入失败与重试按钮改为半透明暗红。
- Three.js 地面从近黑色改为深红透明材质，去掉模型下方的黑色弧面。

## 实际验证

- 新增 E2E 回归断言：模型页主背景和展示框必须包含首页朱红色系。
- `npm test`：6项通过。
- `npm run build`：成功；Three.js既有567.53kB分包提示保持不变。
- Chrome通道开发回归：9项通过。
- Chrome通道生产预览回归：9项通过。
- 实际检查模型页截图：朱红到暗红渐变、模型展示框和深红地面均生效，醒狮模型及右侧内容清晰可见。

## 范围边界

本轮未改首页视频、整体GLB、模型灯光逻辑、热点数据或章节内容；真正Cubism Live2D仍未启用。
