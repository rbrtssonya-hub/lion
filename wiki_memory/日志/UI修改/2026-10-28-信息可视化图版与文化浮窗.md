# 右侧信息可视化图版与文化浮窗

## 目标与结果

按用户指定的 `prompt/prompt_01.txt`，在现有狮相万象页面的研究态增加部位对应的信息图版和文化讲解浮窗；保留左侧主图交接、底部六个入口及完整三维模型。用户提供的参考图片作为视觉验收参照：图版需贴合模型、整张图可点击、文化内容放入第二层浮窗。

## 关键变更

- 使用内置 ImageGen 分六次分别生成眉目、额冠、繁须、织锦、云边、口齿六张 1024×1536 PNG，保存到 `public/images/lion-info/`。织锦额外使用已有模型纹理作为参考。
- `LionBreakdownStage` 在研究态右侧仅放当前图版，无可见文字；主图与竖版图均用 `object-fit: contain`。用户确认比例不匹配时保留完整图片，用纯纸色 `#eeeae1` 留白；无模糊扩边、裁切和拉伸。整张右侧图片为按钮。
- `LionDetailModal` 提供左右双栏内容、独立正文滚动、关闭/遮罩/Escape、焦点循环与返回触发图焦点。窄屏改为上下布局。
- `lionBreakdowns.js` 分开记录模型观察、造型解释与资料事实。来源链接包括中国非遗网、南海博物馆；制作案例、云边称呼和静态口部结构均加边界说明。
- 未拆解或移动模型节点，未修改 `source/科比blend.blend`、GLB、相机登记数据或左侧主图资源。
