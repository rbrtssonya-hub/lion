# 十二项批注与一屏展览整改

## 目标与实现

按十二张批注图及最新补充，首页先向下滚动或点击探索到书页，再通过侧栏切换四个一屏展板；下滑不换板，上滑回主视觉，长资料列保留自身滚轮和键盘。隐藏展板继续挂载，书页和图库只在自身活动时播放。

画册七站并入说明底卡，18px正文与完整纸面同屏；1366/1440/1920实际纸面宽约974/1193/1560px，标题/纸面/底卡边界一致。文化间距收紧、提示与备注分开；狮种默认基础阅读，点击进入实质对照；来源和八份摄影许可保留。结构四处浅折叠直接呈现，结构与剧场卡片各自同族圆角材质。Logo固定左侧，神态提示与列表加浅纸底，活动朱红条延伸到左边缘，真实操作轻微边缘呼吸并遵守减少动态。
