# 导航栏毛笔标题字图

## 目标与结果

按用户提供的“南风有狮”题字参考，为四章导航与设置项生成“序、造、舞、传、设置”五张暖金色透明底毛笔字图，并替换原视觉标题。五张运行PNG直接放在 `source/public/assets/navigation/`，由 `assetPaths.js`、`media.js` 和 `navigationLabelMediaKeys` 统一映射；资产来源、字节大小与SHA256记录在 `source/asset-manifest.json`。

提示词要点：每个标题独立生成、透明画布、暖浅金/象牙色毛笔笔触、与用户附件 `image-2.png` 中品牌字的笔意和浓淡相配；不加背景、场景、纹样或其他文字。“设置”按两个字横向构图；“传”单独强调简体规范构形“亻+专”。提示词为本日志概要，并非逐字转录。

| 导航项 | 运行资产 |
| --- | --- |
| 序 | `source/public/assets/navigation/nav-label-xu.png` |
| 造 | `source/public/assets/navigation/nav-label-zao.png` |
| 舞 | `source/public/assets/navigation/nav-label-wu.png` |
| 传 | `source/public/assets/navigation/nav-label-chuan.png` |
| 设置 | `source/public/assets/navigation/nav-label-settings.png` |

`ChapterNav` 在原有标题几何框内叠放字图，保留按钮的现有可访问名称和辅助文字；标题 `strong` 留作无障碍隐藏的测量文本，图像 `alt` 为空并标记装饰性。`object-fit: contain` 让四章单字及横排设置字适配同一字号框，展开/收拢仍使用原导航行为。
