# 模型页档案布局与首页导航

## 目标与实现

本轮将整体/结构模型页从旧的“模型展示加说明文章”排版调整为“醒狮三维档案”布局：

- 顶部右侧改用首页相同的 `ChapterNav` 首页变体，包含红金章节牌签、搜索和章节菜单工具，并按当前章节高亮。
- 左侧保留三维模型主舞台，扩大主次关系并保留热点、结构拆解和旋转缩放操作。
- 右侧改为半透明深红档案卡，部件资料和六项部件目录在同一信息区连续阅读。
- 左上角品牌统一为“南风有狮 / 广府醒狮档案”；模型状态、返回首页和自动旋转控制保留在导航下方。
- 移动端沿用首页导航的菜单回退，模型内容保持单列并验证无横向溢出。

## 实际验证

- 资产测试：`npm test`，6项通过。
- 构建：`npm run build`，成功；Three.js既有567.53kB分包提示保持不变。
- Chrome通道开发回归：`npm run test:e2e`，10项通过。
- Chrome通道生产预览回归：`npm run test:e2e:preview`，10项通过。
- 记忆体检：`npm run memory:check -- --require-ready`，26页、0错误、0警告。
- 截图确认首页式红金导航、左侧模型舞台和右侧档案卡已生效。

## 范围边界

本轮未替换整体GLB、热点数据、首页媒体或章节内容；动作、神态、评分仍保持现有占位模块。
