# 首页参考图视觉重构

## 目标与实现

基线为 main `51d5886`，工作区开始时干净。按参考图调整首页其他UI，保持现有透明PNG标题、首页视频和醒狮构图。

- 顶部采用暖米白半透明圆角容器，编号在上、宋体中文在下；加入朱红激活短线、细分隔线及统一线性搜索/菜单图标。
- 原版本没有搜索或菜单按钮；新增 `EntryNavTools`，用原生dialog实现章节名称/编号/说明筛选、空结果恢复、Enter跳转和章节目录。Esc、关闭按钮及背景点击关闭，关闭后恢复焦点。
- 入口保留实际原文案“探索更多”和入场视频跳转；重构为红色半透明背景、双层细金边和SVG箭头，悬停箭头轻移。
- 中英文原文案不变，采用宋体中文与Georgia英文、金色细线，加入轻量云纹和底部角线。
- 五个模块保留名称、说明和目标路由，重绘统一金色线性图标；底部改为半透明深红、细金色顶部线/分隔线。手机显示全部五个入口，顶部保留搜索/菜单。
