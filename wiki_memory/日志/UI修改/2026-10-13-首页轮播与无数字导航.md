# 首页轮播与无数字导航

## 目标

将首页下方四段文化图文改为可自动播放的同步文化图鉴，并删除顶部章节数字；保留首页视频、入口行为、章节路由和章节内部内容标记。

## 结果

- 首页文化区使用四个本地文化故事轮播项，图片、标题、正文、文化注释、图注署名、许可链接和进度同步更新。
- 默认每6秒切换，提供上一项、下一项、四个主题指示点和播放/暂停按钮；鼠标悬停、键盘聚焦、页面进入后台时暂停。
- `prefers-reduced-motion: reduce` 下关闭自动切换，仍允许手动切换。
- 新增低对比红墨/卷云/旋眉纹理 `source/public/assets/decor/lion-culture-pattern.svg`，并登记SHA-256到 `source/asset-manifest.json`。
- 顶部五项导航只显示首页、狮头与结构、动作、神态、设置；章节内容中的结构编号与轮播进度继续保留。

- `npm test`：10/10通过；新增动作章节图标路径回归断言，恢复了基线图形路径。
- `npm run build`：成功；Vite保留既有Three.js延迟chunk超过500kB提示（567.90kB，gzip146.85kB）。

- 视觉检查：Chrome开发回归生成的首页文化长页截图确认暖米纸背景、低对比纹理、红金轮播控制和图片/文字/署名层次正常。
