# 整体页数字展厅改版

## 目标

按用户确认的“中央3D醒狮 + 左右动态信息面板”方案，升级《南风有狮》的整体与结构章节，加入部件热点、文化解读、结构工艺信息、镜头聚焦与结构示意，同时保留原有章节导航、视频入口和合并网格边界说明。

## 结果

- `ModelPage` 改为三栏桌面展厅：左侧文化/纹样，中央可旋转 GLB 与热点，右侧结构/材料/工艺/局部层次示意。
- 六个醒狮热点补充了文化寓意、纹样表现、组成、材料、工艺、连接关系和镜头目标；信息来源继续标注为资料整理、结构示意或 AI 辅助创作。
- `lionScene` 增加单一渲染循环内的相机聚焦和复原补间；热点选择暂停自动旋转，重置视角恢复初始相机，不创建额外 RAF。
- 中央模型默认缩小至 `1.78 / maxSize`，2560×1440、1920×1080 检查时完整落在展示框内；原始 `lion-overall.glb` 未修改。
- 桌面端中央模型展示框固定为 `aspect-ratio: 16 / 9`，结构页说明文字上移避开底部拆解滑杆；小屏继续使用横向16:9舞台并保留单列滚动。
- 结构章节保留滑杆，并明确显示“合并网格 · 结构示意”，未伪造可独立拆出的真实零件。
- 模型加载失败时隐藏热点，保证“重新载入”按钮可操作；加载期间选择热点会在模型 ready 后应用最新聚焦状态；模型、页面和路由退出清理逻辑保持有效。

## 验证

在 Windows PowerShell、Node v24.16.0、Chrome 通道下，基于本轮未提交改动执行：

- `npm test`：8 项通过。
- `npm run build`：成功；Three.js 延迟 chunk 仍有既有的 500 kB 体积提示。
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e -- --workers=1`：12 项通过。
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e:preview -- --workers=1`：12 项通过。
- 模型页 e2e 新增中央舞台 16:9 比例断言，通过。
- 视觉检查：1920×1080 整体页、390×844 结构页、2560×1440 结构页；模型完整、面板不横向溢出、导航与结构边界可见。

## 边界与下一步

当前 GLB 仍是单一合并网格，热点和拆解滑杆表达信息关系与结构示意，不等同于真实爆炸拆解。若要实现真实局部分件，需要新的独立部件模型并单独核对。动作、神态、评分章节仍按项目约束保持占位，正式发布和真实设备性能也未在本任务中展开。
