# 神态狮头悬停放大反馈

基于 `main@6fc828d`，在神态页中央狮头图像增加 1.035 倍悬停缩放和 220ms 过渡，仅在支持悬停且系统未启用减少动态时生效。图像层单独缩放，不覆盖点击按钮已有的放大动画。点击反馈沿用 `expressionClickScale` 默认 108%、`expressionClickDuration` 默认 280ms，并保持原有可调设置。
