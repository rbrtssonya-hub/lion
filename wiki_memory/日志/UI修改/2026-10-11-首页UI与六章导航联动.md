# 首页UI与六章导航联动

## 目标与范围

本轮开始于 `main / 810daab8914fd364090738f457888489b947f1ba`，工作区和暂存区干净。附件实际只有要求文本，视觉参照仓库内与描述匹配的 `source/design/final-home.png`，没有声称收到新附的两张图片。

检查确认Hash路由已支持七个状态，但入场无顶部导航，其余章节只有旧金色rail；现用CTA和中文辅助文案与本轮明确文本不同。标题实际是PNG而非CSS文字。用户在本轮明确允许沿用图片等比例缩放微调，后续以此授权替代严格font-size限制；未重写标题、字体或素材。

## 实现

- 首页使用较紧凑的浅米白半透明导航、两行编号/名称、细分隔线及朱红短线；hover本身不增加红色激活线。搜索与菜单保留。
- `App` 在六章显示共享顶部导航，当前项来自既有 `useChapterRoute`。搜索和移动菜单同步 `aria-current`/`is-current`；entry映射intro作为首页入口状态。没有新增路由状态、存储或监听器；刷新和前进后退继续由Hash驱动。
- CTA按指定文本为“进入醒狮档案”，重排到中英文辅助文案之后；使用单层细金边、红色渐变胶囊、暖白文字与线性箭头，hover轻微提亮/右移。中文采用指定文本“广府醒狮的结构、动作与神态”，英文原文保留并加细金线。
- 云纹尺寸/透明度收敛；五入口统一金色线性图标、暖白名称、浅色说明和竖向金线。手机说明提高到12px、英文10px；底栏132px，内容顶端对齐避免单行评分说明导致错位。
- 手机以84px下的原视频16:9区域完整展示狮头，标题/文案在红色背景下继续保持原锚点。桌面视频舞台、原视频播放逻辑、封面和所有二进制素材不改；未生成新素材。

标题只更改已授权的 `--title-scale`：1600px以上1.45→1.32，901–1600px为1.12→1.16，561–900px原1.06不改，560px以下1→0.78。1920px可见图片宽478.5→435.6px，1440px369.6→382.8px，390/414px240→187.2px，375px232.5→181.35px。

`entry-support`保留原辅助UI流高度，避免 `entry-copy` 的居中变换间接移动标题。五尺寸机器对照确认文案容器与标题外层x/y/宽高完全相同；PNG左侧/下沿锚点一致且宽高等比例变化。源码核对全部原标题规则仅倍率变化，`TitleMotionLayer.jsx`与动效不改。证据在 `source/reviews/homepage-ui-2026-10-11/title-verification.json`。

环境：Windows PowerShell，Node `v24.16.0`、npm `12.0.1`、Python `3.14.2`，Playwright使用Chrome通道。适用于上述基线加本轮任务改动；未升级依赖。

- `npm run build`：成功；Three服务原有567.53kB分包提示仍存在。
- 设置 `PLAYWRIGHT_CHANNEL=chrome` 后，`npm run test:e2e -- --output=tmp/e2e-home-ui-2026-10-11-dev-final`：17项通过（21.9秒）。
- 同环境 `npm run test:e2e:preview -- --output=tmp/e2e-home-ui-2026-10-11-preview`：17项通过（23.2秒）。
- 覆盖六章顺序切换、当前项唯一、朱红编号/名称/短线、鼠标移开保持、每章刷新、历史前进后退、非首页搜索、手机菜单当前项、原视频转场、整体/结构热点和滑杆、模型错误恢复及快速进出。
