# 书籍下方投影清理

用户截图标注书本底边下方的不自然阴影。源码确认嵌入书页之外另叠了 ambient、contact、hair 三层 `.sb-cast` 投影；本轮在书本适配文档中隐藏这三层，未修改七幅书页PNG、书本尺寸、翻页曲面或书沟明暗。持续保留纸页素材自带的边缘细节。

验证：Windows PowerShell / Node v24.16.0 / npm 12.0.1 执行 `npm run build`，Vite 7.1.9 转换 345 个模块并成功输出；Three.js 538.05kB chunk 仍提示超过 500kB。未运行浏览器视觉回归，因此本轮记录不宣称实机截图复核。
