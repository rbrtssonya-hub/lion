# 书册下方人物放大与参数公开

## 目标与实现

用户截图指向书页下方年代时间线上的引导醒狮。新增开发者设置 `bookGuideScale`，默认150%，可在“设置 → 首页 → 书册 → 书册下方人物”以100%–200%即时调整、保存并随全局参数导出。正常窗口按96px基准、短窗口按80px基准应用同一比例；同步上移相应半尺寸差，保持人物与年代台阶的脚底关系。原书页、年代切换、动画及粒子行为未改。

## 验证

基线 `main@e2e637c` 加本任务修改，Windows PowerShell / Chrome：`npm test` 112/112通过；`npm run build` 379模块成功，仍提示既有 `lionLightingSettings` 648.67kB chunk 超过500kB；`git diff --check`通过，无运行资产变更。

最终聚焦生产回归使用独立4198端口，3/3通过：书下人物设置可即时调整并保存，150%/125%分别呈144px/120px，短窗口125%呈100px，减少动态时平台脚底偏差小于1px；1920×1080及1366×768的完整书页几何回归通过。命令：`PLAYWRIGHT_CHANNEL=chrome`、`PLAYWRIGHT_PREVIEW_PORT=4198`，运行 `npm run test:e2e:preview -- tests/e2e/book-wave-settings.spec.js tests/e2e/book-screen.spec.js --grep "书册下方人物比例|画册1920×1080|画册1366×768" --output=tmp/book-character-scale-final`。

一次较宽的两文件生产回归为5/9。其余四项分别报告1440×900阅读卡延伸至视口下方、旧固定舞台高度断言680px而实测670px、年代台阶中心差恰为1px，以及短屏播放状态仍为hidden；它们不是本次改动的代码路径，尚未确认是否为基线或测试时序问题，本任务未扩大修复范围。首次该命令误复用了4173端口另一工作区的页面，已改用独立端口复跑；不把错误页面上的结果计入验证。
