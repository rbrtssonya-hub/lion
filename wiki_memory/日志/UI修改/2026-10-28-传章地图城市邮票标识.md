# 传章地图城市邮票标识

地图层级各显示四枚编号邮票，邮票可点选并联动右侧地点卡片；被选邮票轻微上浮，卡片照片使用邮票齿孔边框。广东为佛山、广州、鹤山、遂溪（01–04）；中国为北京、田阳、泉州、香港（05–08）；世界为新加坡、吉隆坡、旧金山、伦敦（09–12）。切换地图范围时只显示该组城市，并默认选中该组第一城。

资料继续遵循现有来源：佛山、广州、香港、新加坡、旧金山保留项目已核验案例；鹤山、遂溪、北京、田阳、泉州、吉隆坡、伦敦目前没有配套来源，卡片显示“醒狮文化资料正在整理”，不借用其他地点的照片或文化介绍。地图地点为近似索引位置，不表示传播路线或历史先后。邮票主题名称与邮票收藏版式未实现。
