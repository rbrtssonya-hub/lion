# 小醒常驻语音讲解

用户反馈原Yaoyao音色不适合桌宠，并要求开启语音讲解后收起聊天框仍能使用语音。用户选择声音方向为“清亮亲切的少女感”。

旧实现的关闭回调及面板 `open=false` effect 都会停止语音，且语音按钮只在聊天框内。本次将播放/停止当前章节的最近回答或导览控件放到桌宠旁；聊天关闭仅隐藏面板，持续播放。切章、面板被设置/全屏遮蔽、页面进入后台仍会停止当前声音；语音开启状态跨章节保留。开启语音后才返回的有效问答也可播放。

已在临时目录生成两段相同文案的离线比较样音：`tmp/xiaoxing/voice-audition/yaoyao-soft.wav`（Yaoyao，音高`+4%`、语速`+2%`）和 `huihui-soft.wav`（Huihui，同参数）。它们只用于用户试听，没有加入部署资产。现行四章WAV仍是Microsoft Yaoyao，用户尚未确认正式音色；不要将临时样音误当作最终选择。

- `npm test`：100/100通过。
- `npx playwright test --config scripts/xiaoxing/playwright.config.mjs`：Chrome桌面18/18通过。覆盖收起后持续播放、桌宠旁重播/停止、切章停止、声音状态和本章切换、语音期间视频静音与恢复音量。
- 临时两段试听已按音色与格式生成，但没有人工听感结论。
