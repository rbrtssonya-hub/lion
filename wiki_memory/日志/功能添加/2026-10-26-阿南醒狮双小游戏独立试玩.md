# 阿南醒狮双小游戏独立试玩

## 目标与范围

用户先要求开小游戏分支、讨论鼓点采青及梅花桩，再明确要求两款先独立完成供看效果、暂不接网页，并选择“国潮手绘＋轻立体”IP。实际在 F盘 `codex/lion-mini-game-2026-10-26`、基线 `37bbecf` 开发；开工原有 `src/App.jsx` 格式dirty、`.superpowers/`未跟踪，保留且排除提交。

## 实现

- 全部试玩文件放在 `source/design/lion-mini-games/`，HTML可直接打开；无新增依赖，无React路由/导航/运行资产接入。`打开试玩.cmd`为本地入口。
- 内置image_gen创作角色工作名“阿南”，1254×1254透明立绘与同尺寸2×2四姿态图集；原始字节保留，完整提示词和布局在ip-brief。图集脚底原始位置存在漂移，shared.js按实测主体裁剪框与统一脚底锚点补偿。
- 鼓点采青25秒、18拍，前三秒示范，首拍4秒、间隔1.15秒，±0.24秒命中、±0.11秒精准。第12次命中触发0.72秒收青至狮口的演绎，持续键鼠输入不自动连击。
- 梅花桩45秒、五落点，按住蓄力、金色段松开跳跃，方向键可微调速度；轻微偏差仍可落地，失误回到上一桩，完成或超时均结算。
- 共用深朱红暖金舞台、角色设定、菜单、结果、重玩、可选WebAudio合成鼓音、单RAF、失焦暂停与低动态偏好。所有游戏统计明确为创意互动成绩。

## 实际验证与修复

环境：Windows、Node24.20.0、Chrome；保留原App格式工作区差异。

1. 两个真实VM玩法检查均先运行观察缺工厂断言失败，再实现后通过；覆盖成功、失误、键鼠按住、重开、自然/超时结算一次，节奏另覆盖12拍采青边界与绘制路径。
2. `node scripts/review-lion-mini-games.mjs`：Chrome直接打开file HTML，**27项通过、14张截图、0 pageerror**。真实keyboard事件完成18/18及5/5，另实际鼠标完成一次落点与一次合拍；覆盖两种桌面尺寸、暂停进度、暂停松键、重玩、弹层焦点、失焦与声音开关。
3. 首轮审查发现角色框叠暂停框的Tab穿透，已改为只保留顶层可见框并恢复原框，补真实Shift+Tab检查；节奏装饰摆动/粒子补减少动态偏好。
4. 两处浏览器初稿断言读取了不存在的debug字段，已改为真实可观察进度与明确phase；补全通关截图时定位到虚拟时间仍随实时时间前进，已使用pauseAt固定时钟后逐步runFor，并非放宽玩法阈值。
5. `npm test`：**78/78**，16张新PNG加入资产清单后共779项；`npm run build`：**354模块成功**，保留既有大chunk提示。`node --check`检查共享壳和游戏脚本通过。
6. 已查看菜单、角色、鼓面、采青中段、蓄力、腾跃、结果及短桌面截图；独立只读代码复核无P1/P2阻塞。工程记忆与diff检查在交付前执行，Git以本日志所属提交及最终remote引用核对为准。

## 边界与接续

本次是完整可玩的独立设计演示。四姿态插画与位移/缩放提供动作表现，没有制作骨骼、眼眉嘴独立绑定或真实舞狮物理模拟；节拍/成绩不代表传统鼓谱、套路、研究样本或正式比赛规则。未补验其他浏览器/操作系统、实体显卡性能、全网站E2E或旧EXE。

入口和源文件都在独立目录，截图在 `source/reviews/lion-mini-games/2026-10-26/`；下一步由用户试玩反馈决定角色造型、节奏手感、落点难度等调整，网站接入等待后续明确指令。
