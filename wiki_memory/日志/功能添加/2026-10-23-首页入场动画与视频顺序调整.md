# 首页入场动画与视频顺序调整

## 目标与结果

按用户追加要求，将首次入场顺序由短片优先改为“水墨入场动画→入场短片→正式首页”。此前的任务日志记录当时已实现的旧顺序；本日志记录新要求及当前生效顺序，不改写历史结果。

## 实现

- 初次进入和“重播入场”现在先挂载 `EntryAnimationOverlay`。同源动画完成消息将 `useEntryPlayback` 切至视频阶段；短片自然结束后进入正式首页。
- 两个阶段均可跳过并直接进入正式首页。沿用 `#skipIntro` 定位，加载动画中的按钮文案为“跳过动画”；短片阶段显示“跳过入场”。视频媒体错误时“继续浏览首页”直接结束入场。
- session 标记在动画或视频阶段首次有效启动时写入，避免刷新后重复；正式首页循环视频只在 loader 结束后开始。
- 更新开发说明与当前架构/概览状态；用户提供的HTML动画资产和视觉未更改。

## 验证

- `npm run build`：通过，346 modules transformed；耗时2.04秒。保留既有 Three.js chunk 超 500kB 提示。
- 构建包含 `dist/assets/loading/entry-transition.html`；动画源文件未更改。未运行 Playwright 浏览器回归，完整顺序尚未在浏览器中实际观察。

## 基线与恢复

开始时 `main` 与 `origin/main` 同为 `8de3bf2`；先前未跟踪的 `model/` 保留。本次只调整首次入场顺序与相关记忆/文档。
