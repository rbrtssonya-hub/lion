# 首页入场短片与动画串接

## 目标与结果

按“入场短片→醒狮水墨动画→正式首页”串接首次访问流程，使用用户提供的单文件动画，结束后回到 React 首页，不另设路由或覆盖正式首页。

## 实现

- `useEntryPlayback` 新增 `video / animation / home` 阶段。短片结束或媒体错误后的继续动作进入动画；原“跳过入场”直接进入正式首页。动画有独立“跳过动画”按钮；“重播入场”从短片开始重播完整流程。
- 将用户提供的自包含HTML放到 `source/public/assets/loading/entry-transition.html`，保留内嵌画作和动画；将原目录跳转改为同源 `postMessage` 完成通知。`EntryAnimationOverlay` 校验来源窗口、同源及消息类型，卸载时清理监听/超时；30秒兜底和 iframe 卸载避免卡住流程。
- 动画期间首页循环视频暂停，动画结束后才播放。离开首页时中止动画状态，返回后显示正式首页。
- 更新 `docs/DEVELOPMENT.md` 的流程说明。未改旧 `assets/loading/index.html`；不相关的未跟踪 `model/` 目录保留。
