# 结构新模型与部件聚焦

## 目标与工作区

用户指定 `model/醒狮_保留UV_三角转四边_优化.blend`，要求结构页改为左侧模型、右侧文字与浮层，点击模型特定结构后聚焦放大。工作区为 E:/数字媒体竞赛/张钧儒/lion，main@1b193a5；开始时只有未跟踪的 model/ 用户输入，没有其他修改或暂存内容。当前 upstream 为 origin/main，普通提交推送沿用根 AGENTS 持续授权。

## 实现

- 指定源文件为完整四足醒狮，不是旧单网格狮头。使用本机 F:/Blender/blender.exe 5.0 读取；源由更高版本写入的兼容提示保留在记录中，未另存或覆盖原件。
- 网页加载 `source/public/assets/models/lion-structure-optimized.glb`，旧 `lion-overall.glb` 原字节归档为 `source/models/lion-head-overall-v1.glb`，不再部署历史模型；资产清单保留旧记录大小和 SHA，仅迁移该记录路径。
- 左侧透明全页 Three.js 画布按左交互区域构图，右侧集中模型状态、复原/旋转、六组部件目录及工艺/文化说明，说明独立滚动。删除固定屏幕百分比热点、虚拟结构滑杆和重复左右卡片；正文增大，900px 电脑余宽仍为二栏。
- Raycaster 命中真实模型表面：眉、耳、角、珠饰、须、身体和尾等按 mesh 名归组；眼与嘴的部分表面以源 glTF 空间区域标识。点选命中点传为世界坐标，列表默认目标为源 glTF 坐标，经模型矩阵转换。相机将选中部位移到左区中心并放大，右侧同步说明。
- 默认停止自动旋转便于点选；支持手动旋转、滚轮缩放和复原。拖动/取消/失焦不误作点击，拖动取消正在进行的聚焦。减少动态时相机直接定位；聚焦后改变窗口再复原时按当前左区重新计算完整构图。
- 保留启动预热及离页暂停、返回复用的单 canvas。PMREM 中性环境只补充 PBR 反射，不添加地面或可见背景；卸载/重试清理模型、环境渲染目标、renderer、观察器、RAF 和指针监听。

上述源坐标映射、静止默认旋转、右侧独立滚动、源曲线近似及中性反射环境，均为 Agent 根据用户已授权目标、源文件实况和原生命周期作出的实现选择；并非用户要求将内部结构重建或制作动画。

## 资源与真实性边界

源文件 139309821B，SHA256 为 `2230dbce24b0d9bead0b6781410cfbb9acf6d249c99113210f21ba0b16991bd2`。用户原件留在 model/，未修改、不直接纳入普通 Git（超过 GitHub 单文件限制）；网页派生文件及可复现脚本纳入工程。

导出保留 UV、可识别部件和内嵌纹理，剔除经完整属性核对的重合副本；Blender 毛发曲线转换为确定采样的双面细带，属于网页显示近似，不宣称无损毛发导出。颜色 JPEG 和标准 KHR_mesh_quantization 减重，浏览器无需额外解码器。最终 GLB 为24428652B，SHA256 f4f7f6a25f84d8457afd6fd42e44702607213b037613d019b936d10c4422b0e0；41 mesh / 41 node、720271三角、885411顶点、6张内嵌JPEG。精确设置与严格副本核对见最终导出 JSON/来源说明。

首轮视觉审查的足部黑色碎块已定位为 procedural Bump 导出错误地把灰度遮罩当成法线图。只在网页导出副本中取消不受支持的 Bump 连接，保留真实 Normal Map、颜色、粗糙度与金属参数；不是重新解释模型材质或重画原件。纸扎内部骨架、隐藏连接和活动机构仍为工艺资料说明，不把可见分区称为内部拆装。源属性只说明颜色派生 PBR，未证明 AI/Lux3D 来源，不新增未经证实的来源结论；原首页视频等既有 AI 标识保持。
