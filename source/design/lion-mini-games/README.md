# 阿南的醒狮游园 · 独立试玩

本目录保留《南风有狮》两款小游戏的**独立设计初稿**，包含可玩的演示与 AI 辅助原创醒狮角色“阿南”。2026-10-26用户后续要求接入工艺展板，现用网站版本位于 `src/features/mini-games/`，从“造 → 工艺”的两个入口打开；本目录仍可独立打开，不作为第二个网站入口部署。

## 打开

双击 `打开试玩.cmd`，或直接用 Chrome / Edge 打开 `index.html`。完整保留本目录，尤其是 `assets/`。无需安装依赖或联网，不需启动 Vite。

## 操作

- **鼓点采青**：25 秒、18 拍。前三秒看示范；金圈收拢到目标圈时，按一下空格或点击舞台。每次松开后再按。命中、精准与连击均来自本局输入。
- **梅花桩落点**：45 秒内完成五个落点。按住空格或舞台蓄力，指针到金色区域时松开跳跃。左右方向键可以微调蓄力速度；失误会返回上一根桩。
- **Esc**：暂停 / 继续；窗口失焦或切换标签会暂停。
- 右上角“声音”由用户主动开启，使用本地合成鼓音。声音关闭时视觉节拍仍可玩。
- “认识阿南”可查看角色设定；游戏进行时打开会暂停，关闭后自行继续。

## 视觉与内容边界

用户已于 2026-10-26 选择“国潮手绘＋轻立体”风格。角色用朱红、米白、少量金色保留南狮圆眼浓眉、额镜、狮口与短狮被。工作名“阿南”可继续调整，提示词及原始资产来源见 [ip-brief.md](ip-brief.md)。

游戏使用待机、蓄力、腾跃、落地四张姿态与实时位移/缩放构成反馈；未制作骨骼动画或独立眼眉嘴绑定。当前节拍、跳跃与成绩是创意互动设计，不代表传统鼓谱、正式套路或赛事评分。

## 文件

- `index.html`、`styles.css`、`app.js`：独立界面、输入、暂停、结算和单动画循环。
- `shared.js`：统一舞台、图集锚点补偿、合成音效。
- `rhythm.js`、`poles.js`：两个独立玩法实例，无外部引擎。
- `assets/`：1254×1254 透明角色立绘与 2×2 动作图集。
- `rhythm-check.cjs`、`poles-check.cjs`：真实玩法逻辑检查。

## 复核

在项目根目录执行：

```text
node source/design/lion-mini-games/rhythm-check.cjs
node source/design/lion-mini-games/poles-check.cjs
node --test tests/assets/mini-games.test.mjs
npx playwright test tests/e2e/craft-mini-games.spec.js
```

本目录两个CJS检查复核独立原稿；现用React引擎与工艺入口由后两条命令复核。工艺入口专项截图保存在 `source/reviews/craft-mini-games/2026-10-26/`，实际接入验证和范围见工程记忆中的本轮交付日志。
