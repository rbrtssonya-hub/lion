# 醒狮八态 · 独立纵深版

当前版本：2026-10-28 V7 点击观态与慢速巡游。到站狮头静止，点击主狮头或“观狮头”后播放原3秒五官动作，结束才打开当前态解读；巡游中的解读12秒后自动收起，约6秒缓慢移至下一站。已修复重渲染导致的整头闪灭，并加入用户审核通过的Q版醒狮路线图标。保留暖纸背景、朱砂飞白标题和原相机空间路径。历次ZIP另行保留。

根据用户提供的《炫技2》纵深版改编，以喜、怒、哀、乐、动、静、惊、疑替换风景作品与介绍文字。本目录是独立工程，未导入《南风有狮》现有网页。

## 直接看效果

1. 双击根目录 `runStart.cmd`。
2. 浏览器自动打开 **http://127.0.0.1:5198/**。
3. 滚轮向下前行、向上回望；左侧醒狮红签目录可直达八态。到站狮头保持静止；点击狮头或“观狮头”，播放约3秒五官动效后打开当前态解读。面板只展示本态，不提供切态；Escape关闭。减少动态或图形后备时直接打开解读。
4. 点击“自动讲解”启用旁白。稳定进入一态后自动播对应普通话讲解，切态时停止上一段；可暂停、继续、重播。手动打开解读面板会暂停旁白，关闭后恢复此前播放意图；巡游解读期间旁白可继续。默认保持安静，需点击一次启用。
5. 结束后在预览窗口按 `Ctrl+C`。

顶部中间“自动巡游”开启缓慢运镜与讲解，从当前站继续。抵达八态后保持静止并等待点击，点击才播放该态一次五官动作；动作结束自动打开当前态解读，阅读约12秒后收起并前往下一态。可在面板内“提前继续巡游”；关闭或Escape同样提前前行。页面暂离会暂停读秒，恢复后点击面板内“继续巡游”。滚轮、滚动键和手动选态会交还手动浏览；动效中接管会取消本次动作，不弹旧态解读，重新点击可再次播放。重复点击不会叠加动作。默认不自动启程。

五官动效保留原工程逐态眉、眼、狮口的三秒双峰动作和参数。进入或返回一态均不自动播放。减少动态偏好或图形后备时保持静态可读，点击直接打开当前态解读，不模拟五官动画。

预览只需要已安装的 **Node.js 22.12或更新版本**，不必安装项目依赖。启动器使用Node自带HTTP服务读取随包附带的 `dist/`。请通过启动器访问，直接双击 `dist/index.html` 不适合此模块化网页。

若5198端口已运行同一个图鉴，启动器复用它；若由其他程序占用，会提示冲突，不会停止别的程序。

## 镜头保真范围

沿用附件 `炫技2/versions/depth` 的React、R3F、Three、Lenis和GSAP架构及锁定依赖。保留开场后退、原前四站相机坐标、FOV40、13.5焦点距离、36单位站距、原图框世界尺寸及XYZ、近处掠过、悬停、指针视差和文字单进度同步。

八态比原四个作品多四站，因此按原站距延展路程：主站相机Z为 `-28 / -64 / -100 / -136 / -172 / -208 / -244 / -280`，末点 `-318`。原开场 `20 → 48` 保留；每段14%起始停留、72%旅行、14%结束停留的五次平滑曲线保留。总路程增加，纵深间距没有压缩。原空间曲线保留全部控制点后向远方追加，尾景后移144单位。

方形透明狮头保持原世界尺寸与位置，保留眉眼、狮口和须毛；可见绘制已无米色底板、边框。稳定停靠只显示当前1个狮头，过渡最多相邻2个，远处用透明态名/编号代替复制图；狮头平面Z倾角由±0.027减为±0.007，真实相机与掠过数学保留。V5将原网页五官分层动作移植到同一父平面，采用补绘底层、五个移动片与固定前景；局部动画保留原轮廓、枢轴、幅度、延迟和3000ms原生WAAPI时序。八态排列用于浏览分类，不表示固定情绪发展顺序。

## 图文来源与边界

八张1254×1254 PNG来自现有《南风有狮》八态素材，原字节复制，没有重绘。文案来自原 `lion-expressions.js` 的简介和定性观察提示，未加入新历史断言、识别算法或评分。逐图来源、大小和SHA见 `reference/ASSET-SOURCES.json`。

图像属于 **AI辅助示意**，八态属于本项目的定性观察框架，等待真实图片/视频样本校核。理解醒狮表演仍须结合情节、锣鼓、身段与连续动作。

图片、运行脚本与三套开源字体均在本地。V5首页标题和阵心使用新生成的透明飞白字谱，八态字谱与各态红标题复用主工程原毛笔字图；来源、实际prompt和SHA见 `reference/BRUSH-GLYPH-SOURCES.json`。字图为AI辅助创作，以CSS透明蒙版上色，保留真实DOM中文。副标题和每态正文采用Noto Serif SC，播放器与通用UI采用Noto Sans SC，其他毛笔文字采用Ma Shan Zheng；字体授权保留于 `public/fonts/`，来源和实测见 `reference/TYPOGRAPHY-SOURCES.json`。侧栏态名优先使用系统STXingkai（华文行楷）400字重，本包不分发该系统字体，未安装时使用随包毛笔字体后备。V7巡游UI已补齐本地字体子集；修改文字后仍须检查覆盖。背景参考来自用户提供的《醒狮模型背景.png》，低透明度用于纸色和边缘水墨氛围。减少动态偏好、WebGL不可用或 `?static=1` 时保留可读常规图鉴。此次以电脑浏览器为目标。

五官补绘图、源轮廓和动作参数来自原主工程，同样属于AI辅助示意。八张补绘原字节复制，并保留原组件与profile源码快照，来源与哈希见 `reference/FACE-MOTION-SOURCES.json`。网页不请求主工程路径，也不依赖外部视频链接。

路线标记当前采用用户2026-10-28审核通过的Q版醒狮，AI辅助新生成并具有真实透明通道。当前提示词、审核记录与哈希见`reference/UI-MARKER-SOURCE.json`，旧用户原图与处理记录保留于`reference/ui-lion-marker-original.png`及`reference/UI-MARKER-SOURCE-v4.json`。侧栏选中图片仍使用各态原图，与路线图标分别绑定。路线仍由相机Z求原曲线位置，向后滚动重走同一条线，没有改变站位。

旁白是本地合成语音，采用Windows System.Speech/SAPI的Microsoft Huihui Desktop普通话女声，非真人录音。Qwen环境未安装，未下载大模型；网页运行直接播放随包WAV，不依赖系统是否装有该音色。内容严格取每态原有标题、副标题和三行介绍，来源与引擎记录见 `reference/NARRATION-SOURCES.json`。修改文案后需重生成相应音频；`scripts/generate-narration.ps1`在具备该Windows声线的电脑上可复现。`scripts/update-font-subsets.py --check`核对字体，`--update`从官方获取当前文本子集（开发时需要fontTools与Brotli解码环境）。

`review/v5`中的WebM是浏览器画面演示，不含系统音频；实际旁白请在预览中启用，或直接播放`public/audio/*.wav`。
