# 音量控件放大与像素参数

用户要求根据附件放大右下角音量控件、加长波浪线，并在设置公开参数。基线为 E 盘 `main@3f51884`；起始 fetch 后 `origin/main` 与 HEAD 一致，原未跟踪 `model/` 保留。

“设置 → 公共模块 → 声音控件”现提供三项实际 CSS 像素参数：

| 参数 | 默认 | 可调范围 |
| --- | --- | --- |
| 音量文字字号 | 16px | 12–28px，步长1 |
| 音量控件宽度 | 180px | 140–300px，步长1 |
| 波浪线长度 | 64px | 40–120px，步长1 |

默认由原12px/112px/26px放大，数字、波浪高度、滑杆触点按字号同步放大。尺寸在首页与动作页共用，同一事务支持即时预览、保存、取消、恢复默认和当前参数 JSON 导出；旧存储缺失项补新默认。字号较大且控件窄时，文字和波浪自动换行，仍保留所请求的实际像素宽度。首页短窗按控件宽度预留独立右侧区域；动作宽窗的解读底距按控件高度计算，窄窗继续使用原自然阅读布局。

波形扩为8组完整周期，SVG增加足够长的平直尾部；最小字号配最长窗口时，启声仍覆盖全窗并在固定位置持续右行，静音后全长变为直线。独立审查发现初稿波形与尾部之间存在短暂空缺，已将尾部起点移至移动波形最短终点565.5。生产浏览器在16/12px、64/120px窗、3个流动相位、16个过渡时点共96组各129个横向位置实测均覆盖，0缺口；截图也复核了中间态。
