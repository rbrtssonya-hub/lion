# 连续声线与交互整改

基线：E盘 `main@b2009f0`；开始任务时 fetch 后 HEAD 与 `origin/main` 一致，原未跟踪 `model/` 保留。用户持续追加了五项要求，按指定先后顺序实现及阶段验证。

## 1. 连续声线及公开形状参数

旧双路径的 hover 描线会互相擦除。已在生产浏览器复现附件中的三条分离斜线：默认64px窗口的200ms悬停中段有41.5px横列无墨，最长断口14px；这是控件动画，非视频重载。旧几何覆盖检查未计入dash，不能证明实际笔画连续。

现在使用单条连续的周期三次曲线，相邻段和周期的切线连续，整周期向右平移；悬停只调整透明度。静音改为250ms纵向压平，不再横向扫过长尾；非缩放描边保持像素粗细。极小非零纵向缩放避免浏览器在奇异矩阵下丢失笔画，24px幅度压平后偏差小于0.003px。默认及范围由Agent按本轮要求选择：

| 设置 → 公共模块 → 声音控件 | 默认 | 范围/步长 |
| --- | --- | --- |
| 波浪线粗细（也作用于静音直线） | 2px | 0.5–6px / 0.5px |
| 波峰高度（相对中线向上） | 10px | 0–24px / 1px |
| 波谷深度（相对中线向下） | 10px | 0–24px / 1px |
| 波长（相邻波峰间距） | 32px | 16–80px / 1px |

上一轮的字号、控件宽度和可见线段长度仍可独立调整。新参数沿同一设置事务支持即时预览、保存、取消、默认恢复和当前参数JSON导出。原生媒体音量、播放授权、主屏独占、后台暂停与资源清理保持。

独立原生浏览器DPR4截图采样12组参数×14状态，共168张，全部480个横向像素列有笔画；静音线积分厚度约0.505/2.007/6.007px。循环尾帧与首帧平均灰度差最大0.0272/255，没有可见相位跳变。包含悬停、离开、零/单边峰谷、最细/最粗、16/80px波长、静音中途和快速反转。审查时仅临时隔离黑底、白线和透明度，不修改几何/播放；[汇总](../reviews/sound-wave-stability/2026-10-22/native-raster-summary.json)，原168张临时图在`tmp/wave-native-raster-review/`，不部署、不全部入库。普通页面QA包含7张最终声线图，另存旧断层原生图供对照。

## 2. 神态悬停假内框

删除 `.expression-lion-trigger::after` 的金色椭圆及其hover显现规则。真实悬停、鼠标点击后均无该伪元素、边框或阴影；保留原笔触三圈和键盘focus-visible轮廓。点击解读、滚轮/前后切态和Enter/Escape保持。三张原生图位于`source/reviews/expression-hover/2026-10-22/`。

## 3. 照片右侧区域点击轮播

原画廊仅前景射线命中能切图。现在前景正常边界的右缘至图库canvas右界之间（包括后排照片与空隙）都可点击下一张，并允许其余可见后排照片命中。只在真正canvas输入位置生效，排除左侧空白、上下装饰、图外正文及来源链接。

前景微放大/悬停暂停依旧只由前景命中产生，点击右带不额外暂停。静态、减少动态和WebGL失败回退共用边界，原按钮不双发；失焦、隐藏及离屏清光标和旧指针，可见加载交接仍保留真实输入。未新增常驻动画帧。新回归实际覆盖1920/900/640窗口，图文、原生画布像素、一次一步及链接弹窗均实测；三张阶段图位于`source/reviews/culture-gallery-click/2026-10-22/`。

## 4. 结构视角现场调参

`sceneViewEditing` 将原动作规则扩展到结构页，条件严格是结构/动作路由的“视角”分类。移除外部点击guard，主视口真实旋转/缩放可用；Escape、设置导航保持打开，关闭X隐藏，保存后继续编辑并更新取消基线。只有点击取消退出，存在未保存修改时沿用确认与回滚。其余分类及首页/神态事务保持。

生产回归验证真实表面投影移动、相机距离变化、同一画布、三个电脑布局、连续保存、默认恢复、取消到最近保存值及存储失败。原动作和视角/事务回归同时通过。两张模型现场调参图位于`source/reviews/structure-view-editing/2026-10-22/`。

## 5. 神态点击反馈

“设置 → 章节 → 神态 → 狮头点击反馈”新增放大比例及反馈时长。默认由原101.5%/180ms增强为108%/280ms；放大可调100–120%，时长120–800ms、步长20ms。100%关闭脉冲而不影响解读，减少动态也不播放反馈。尺寸按所选峰值预留上下箭头间隔，短窗完整呈现，基线布局在空间足够时保留。反复点击、切态、对照、离页和参数变化取消旧反馈，仍只保留原触发器。
