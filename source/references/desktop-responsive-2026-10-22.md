# 全站电脑自适应（2026-10-22）

用户目标：所有现用组件和显示应适应不同电脑。沿用根 AGENTS 的电脑端范围；窄窗口与浏览器缩放后的 CSS 余宽仍按电脑验收。

## 验收要求

| 范围 | 要求 | 直接证据入口 |
| --- | --- | --- |
| 全局导航 | 所有章节与设置可达；首页完整标题和辅助文字保留单行；不足时整项换排，短窗不被吸顶导航占满 | `navigation-settings-desktop-layout.spec.js`、原导航动画回归 |
| 设置与确认 | 低窗/最窄与最宽侧栏可操作全部分类和保存、取消、导出；确认框可滚动；窗口变化不写入参数 | 新导航设置专项、`settings-transaction.spec.js`、`desktop-window-contract.spec.js` |
| 首页 | 首播无导航、循环首屏主操作可达；史册真实纸面及七页时间线适配；图鉴、传承展开/对照、资料正文和许可不横向裁切 | `home-desktop-layout.spec.js`、对应旧首页回归 |
| 结构 | 模型画布随尺寸改变，目录和资料独立滚动，六部件选择与末尾资料可达，画布实例保留 | `chapters-desktop-layout.spec.js`、结构原回归 |
| 动作 | 场景、解读、四动作选择、播放进度、声音与失败提示不互相遮挡；支持平面观看、全屏和尺寸往返 | 新章节专项、巨幕/导航背景原回归 |
| 神态 | 八态、简介、解读和三组对照完整可读，狭窄纸面具备阅读下限，返回交互保持 | 新章节专项、神态和内容对照原回归 |

## 已核实问题与实现

- 旧 `<700px` 手机导航分支在640×480电脑余窗中将导航画到116px顶栏之外，并隐藏辅助字。改为统一真实字体测量，普通窗口保留现有布局；需要时整项换排并局部滚动，渲染高度最多占短窗约45%。保存的字号/高度不改。
- 首页原620px最小首屏高度使480px高电脑窗口的主操作落到屏外。短屏布局按真实导航下剩余高度排列；书台同时约束实际容器宽度和可用高度，七页台阶限制在自己的格内。
- 首页图鉴原窗口断点不能反映侧轨/设置推开后剩余内容宽度。改为实际容器查询，窄时图文和摄影许可分列为上下布局；正文纸面和资料卡在窄电脑保留阅读宽度下限，原百分比参数仍保留。
- 动作页640×480时绝对定位的解读框和播放器实际交叠。布局监听实际场景宽度、导航高度、resize和全屏变化，在空间不足时保留一屏场景，再纵向排列解读、播放器、声音和提示。原三维服务、视频和大屏四角布局保持。
- 神态40%纸面和大字曾形成138px阅读列。正文纸面使用所在列内的220px可读下限，长说明/返回文案可换行，不缩小用户字号。
- 设置半高背板在低窗压缩滚动区；确认框无视口高上限。现在派生高度至少为480px与视口较小者，最高为实际视口；确认框独立滚动。最宽侧栏给拖动边界保留12px，顶栏句柄使用实际侧栏宽。
- 所有路由的设置推开统一按真实页面宽度扣除侧栏和稳定滚动条；空间不足临时覆盖。视频失败提示按宿主宽度和视口高度钳制，900px偏好不能把重试/继续按钮推到屏外。
- 独立交叉审查补获640×360首页PNG按钮横向裁切，以及180px顶栏组合下英文末行越界。短屏父容器宽度改为题图/按钮较大值；≤440px高时改左题图、右按钮及标语，为右上重播留空。新增检查实际PNG、两朵云与所有首屏文案左右/上下边界及互不遮挡，四组合生产复核关闭该问题。

本次没有使用全页等比缩放，也没有以全局横向裁切掩盖越界；没有更换字体、视频、模型或创作源文件。普通宽屏继续采用原视觉，低窗允许内容自然纵向滚动。

## 验证与边界

实际命令、逐阶段结果、截图和资产检查以同名 `desktop-responsive-2026-10-22-validation.json` 为准。实现基线为 `main@8e1072b` 加本任务工作区，开始时只存在未跟踪的 `model/`，保留不动。

最终核心73/73、341模块构建与生产相关55/55通过，其中包含全部30个新增自适应用例。开发旧回归分组保留了失败及恢复记录，不能描述为某次全量全绿。10张生产QA已逐张查看，0 pageerror；原640条资产记录不变，追加11条至651，141份运行资产和dist逐项SHA256一致。独立审查发现的短屏首页P2已修复并实际复核。原有Three块538.05kB提示保留。

本次电脑窗口覆盖640×360、675×403、640×480、800×600、900×600、1024×576/640、1280×720、1366×768、1920×1080、2560×1080和3840×2160，并检查设置推开后的实际余宽。浏览器缩放采用临时独立profile中的Chrome原生设置，观测CSS viewport与DPR变化且CSS zoom保持1；临时profile不接触用户浏览器。

这是本机电脑Chromium的网页布局验收，不等于任意硬件帧率保证、实体显示器/系统DPI实机矩阵、其他浏览器、手机、EXE重新打包或正式托管验收。HEVC解码和完整模型加载量保留原有平台边界。
