# 四面观狮：柔和空间过渡与公开参数

本轮基于 `codex/huangzhi_ARUI@ce97297`，落实用户后续[柔和过渡要求](../design/action-theater/2026-10-21-soft-spatial-ui-brief.md)，沿用[原参考图](../design/action-theater/2026-10-21-floating-ui-reference.png)的深茶底、金边、云纹、宋体与章印。该要求替代前阶段瞬时显隐；相机响应、角度识别和高亮仍逐帧即时更新。

## 世界绘制与过渡

`actionTheaterSpatialUI.js` 在同一 Three.js 场景中建立真实平面，Canvas2D 在初始化时生成固定内容纹理，四幕的选中/未选中纹理提前缓存并上传。采用深度测试，文字、边框与背景均由场景深度缓冲裁决；不再把可见 DOM 直接盖在狮体之上。原 DOM 保留语义与透视按钮命中，视觉透明；世界矩阵与 GPU 平面完全一致。键盘焦点和悬停由深度测试的金色轮廓反馈。

前方标题放在外圈斜置世界锚点，四块解说牌分别对应四幕世界坐标。锚点只在画布尺寸或缩放参数变化时重新适配，相机旋转不移动锚点。解说牌底边高于地台，避免真实深度开启后被地台切掉。顶栏、底部罗盘、导航和播放控件保持稳定的视口布局。

唯一场景 RAF 在相机矩阵更新后，同帧计算屏幕方向/法线/视锥资格、角优势迟滞、各面板四角投影边界与边缘可见度。新的激活 ID 立即提交，旧说明的目标透明度降至零，新说明从当前透明度趋向其新目标，允许短暂交叠。视频继续使用既有独立异步播放器和 revision，播放/解码不阻塞空间状态。

`actionSpatialMotion.js` 使用基于 delta time 的指数插值：配置时间为完成目标变化约95%的时长。淡入/淡出分别取值，反向操作直接从当前 alpha 接续，没有动画队列。12%边缘区根据实际投影边界提前降低目标透明度，并结合面板投影宽高向外延伸少量过渡空间，面板完整退出前目标已为零。空间投影没有时间阻尼。减少动态偏好保留80ms短过渡。

低于交互阈值或已离开有效几何视野的按钮禁用指针与键盘命中。点击可见按钮还通过射线检测真实不透明网格遮挡；被狮体/建筑挡住的区域交还场景拖动。射线只在指针事件中执行，排除完整毛发线段，避免逐帧昂贵相交检测。完整模型、所有毛发、HDRI及原视频字节保持。

## 参数入口

打开「设置 → 章节 → 动作 → 空间悬浮UI」。数值立即应用于现有场景，不重新创建画布；存入既有浏览器偏好。专用恢复按钮只复原本组七项。

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 渐显时间 | 380ms | 150–800ms，步长10 |
| 渐隐时间 | 320ms | 150–800ms，步长10 |
| 视口边缘区域 | 12% | 5–25%，步长1 |
| 交互透明度阈值 | 35% | 10–80%，步长5 |
| 角度迟滞 | 7° | 3–15°，步长0.5 |
| 不透明度 | 100% | 40–100%，步长5 |
| 面板尺寸 | 100% | 75–125%，步长5 |

角度迟滞是候选巨幕相对当前幕的匹配优势差值，不是固定转向角。默认值符合本次渐变建议，较大范围供用户调整。若不透明度低于所设交互阈值，世界按钮按该设置保持不可交互，底部导航与播放器仍可用。

## 复现与证据

```powershell
npm test
npm run build
$env:PLAYWRIGHT_CHANNEL='chrome'
npx playwright test tests/e2e/action-spatial-soft.spec.js tests/e2e/action-spatial-ui.spec.js
node scripts/audit_action_soft_ui.mjs
```

专项使用真实鼠标慢转/转回、快速90°、边界往返、低透明度命中与实际参数修改。`action-spatial-hit.spec.js` 额外使用原生鼠标验证低alpha直接命中画布，以及现有醒狮实体挡住按钮后，阻止选幕/恢复播放并交回场景拖动。深度用例在开发服务响应中临时注入句柄，将真实标题平面放在完整狮体后，固定相机和姿态，并冻结每路视频纹理，比较无UI、正常深度和关闭深度三次实际GPU缓冲；限定真实投影ROI，并记录ROI外变化（允许最多1级8-bit量化误差），排除视频与HTML时钟污染。这些探针不进入产品代码。生产图集另用生产构建及真实输入生成。运行旧红金用例时设置 `ACTION_THEATER_REVIEW_DIR` 到临时输出目录，避免覆盖历史图集。

最终运行结果与边界见[验收记录](action-soft-spatial-ui-2026-10-21-validation.json)，图集在[本轮审查目录](../reviews/action-theater/2026-10-21-soft-ui/)。前阶段的60项/330模块及旧CSS投影截图只保留历史意义。
