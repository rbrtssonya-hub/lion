# 已知问题

## 未解决问题与影响

| 现状 | 影响与边界 |
| --- | --- |
| 源模型破面及部分共面发射面 | 未全面重拓扑或补面，某些视角仍有几何瑕疵；运行时材质深度偏移仅减轻共面闪烁。 |
| Blender 毛发及程序材质转换限制 | 网页保留基于真实曲线和父毛路径的派生毛发，但没有逐根还原全部子毛，微织纹也未完整烘焙。 |
| AI 图片与模型差异 | 各图锁定真实终点的主要构图，但材质和局部轮廓有艺术差异，不是逐像素配准、模型实测或历史照片。 |
| 信息图为生成式艺术示意 | 六张右侧图依据实际部位近景生成，可能重绘局部纹样或材质；浮窗明确说明图版不是模型拆件或测量图。 |
| 信息图素材体积 | 六张 PNG 均为 1024×1536，总计约 18.3 MB；运行时仅在进入对应章节时加载，但静态部署仍需提供完整文件。 |
| 窄屏页面边界 | 文化浮窗在窄屏纵向排列且正文可滚动；其余醒狮页面仍以桌面布局为主，未做全站手机适配。 |
| 非标准桌面比例 | 用户选择完整图片与纯色留白，若主体在图片边缘，图像和留白的内部边界可能可见；不采用模糊扩边，也不裁掉原图。 |
| 资源和性能 | GLB约35 MB、约162万模型三角面，另有PNG和GPU纹理成本；Three构建块体积提示仍在，未给出跨GPU帧率保证。 |
| 数字模型边界 | 尺度没有实物单位标定；模型无骨骼或口部表演动画。旧 `CulturalPanel.jsx`、分析图和文化数据仍保留在代码中，但当前正文由新浮窗承载。 |

## 复现与临时处理

模型差异可在首页旋转或运镜终点观察，源与派生审计见 `MODEL_AUDIT.md`。宽屏主图对照 `artifacts/fullscreen/reference*/<id>.png`；信息图参考视图及资产哈希见 `artifacts/lion-info/IMAGE_PROMPTS.md` 和 `asset-manifest.json`。HTTP 端口以当前进程输出为准，历史端口不代表当前活跃。

## 证据与未核实项

2026-10-28基于 `56e01b6` 加本轮改动；旧模型限制来自审计，新信息图边界来自 ImageGen 提示与浮窗内容。`npm test` 12/12，构建、开发/生产六章浮窗、四比例图版、交接与视口检查通过，证据见 `artifacts/lion-info/validation/`。跨浏览器、GPU性能和远程发布未核实。
