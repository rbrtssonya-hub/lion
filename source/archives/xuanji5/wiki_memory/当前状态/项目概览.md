# 项目概览

## 项目目标与阶段

《狮相万象 / THE LION ATLAS》是基于用户真实醒狮模型的桌面优先交互式信息可视化。首页显示完整模型和六个艺术入口：眉目、额冠、鬃须、织锦、云边、口齿。选择后相机在整窗飞向部位，再交接给同视角宽屏主图；图片缩至左上，导航左移，右侧显示对应的竖版 ImageGen 图版，点击整图打开文化讲解浮窗。原模型不拆解。[页面](../../src/components/AtlasExperience.jsx) · [浮窗内容](../../src/content/lionBreakdowns.js)

六个章节各有四种桌面比例的 imagegen 主图，共24张；源模型、旧主图及文化组件和素材保留。图片是艺术转译，不等同实测模型或历史照片。[提示与来源](../../artifacts/fullscreen/IMAGE_PROMPTS.md)

## 核心入口

- `src/main.jsx` → `src/App.jsx` → `src/components/AtlasExperience.jsx`：页面和交接；右侧入口与浮窗分别在 `src/components/LionBreakdownStage.jsx`、`src/components/LionDetailModal.jsx`，样式在 `src/components/lion-breakdown.css`。
- `src/model/LionWorld.js`、`src/interaction/layout.mjs`：整窗渲染、登记光圈、相机与版面。
- `public/images/fullscreen/`、`public/images/navigation/`、`public/images/lion-info/`：现用主图、六个艺术入口和六张讲解图版。
- `README.md`、`VISUALIZATION_DESIGN.md`、`MODEL_AUDIT.md`：运行、设计及模型审计。
- 工程记忆协议为 `wiki_memory/AGENTS.md`，逐轮本地提交规则为根 `AGENTS.md`。
