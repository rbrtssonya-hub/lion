# 当前约束

## 用户要求与技术约束

1. 工程记忆使用项目内 standard 模式；每次完整对话的有效项目修改须验证、审查后本地提交，最终回复给提交号。无改动不创建空提交。
2. 桌面优先；本次提示明确要求窄屏浮窗纵向排版，不扩展其他手机端优化。用户参考图用于检查模型一致性、整图可点击、浮窗作为第二层阅读。
3. 保留完整三维模型，不拆解、不做部件爆炸或节点位移；不得覆盖 `source/科比blend.blend`。ImageGen 图版中的空间层次只是艺术示意。
4. 首页为完整模型与六个 imagegen 艺术入口；六个部位各有与原相机终点对应的宽屏主图。整窗运镜后原地交接，主图完整等比显示，不添加模糊、拖尾或遮罩；替换完成后隐藏并暂停模型，再 GSAP 缩图贴左上、导航左移。
5. 研究态右侧仅显示当前部位对应的完整 ImageGen 图版，不叠加标题、图注或说明文字；点击整图进入文化讲解浮窗。文化正文只在浮窗中显示。图版与主图均完整保留；窗口比例不匹配时用纯纸色留白，不模糊扩边、不裁切。
6. 文化事实、当前模型可见特征和艺术示意分开标识；不把生成图当实测数据或历史照片，不给无法确认的工艺、纹样和机构下确定结论。左上印章图标保持移除。

## 兼容性与操作边界

桌面 Windows 本地项目依赖 WebGL、Draco 和静态资源，必须通过 HTTP 加载。相机位置、目标、FOV 或模型尺度改变可能影响主图衔接，修改前核对登记数据并重生成相应主图。右侧竖图以 `contain` 显示；文化浮窗独立滚动，遮罩/关闭/Escape 可关闭并恢复焦点。当前授权包括本地提交，不自动包括远程建仓、推送、强推或重写历史；应保全其他任务改动。
