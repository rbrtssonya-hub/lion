# 清晰全屏图与空白右区

用户要求清空六章右侧文化内容但保留展示区域，生成与整窗真实模型终点相同构图的全屏图片，并明确禁止画面边缘模糊。对不完全匹配的窗口比例，用户选择完整保留图片并允许少量纯色留白。

各部位按16:10、16:9、约1.882和约2.37比例分别以 imagegen 生成全屏主图，共24张；真实镜头截图、风格参考、提示词和生成来源见 `artifacts/fullscreen/IMAGE_PROMPTS.md`。图片以 contain 显示，模型光圈按所选图像注册并扩展至窗口边缘；透明模型层位于图片上方同步淡化。图像完成替换后模型隐藏暂停，GSAP 缩小图片至左上、导航左移，右侧留空。旧文化组件和素材保留但不挂载。

验证基于 `main / 7a492fe` 加本轮改动：最终构建、`node tests/handoff-browser.mjs` 的六章动态、终点、返回中断、三阶段窗口变化、真实拾取及失败恢复，`node tests/viewport-browser.mjs` 的四档和中间比例检查，以及生产眉目章普通动态黑盒检查均通过；结果分别见 `artifacts/fullscreen/final-verification/handoff/browser-results.json`、`artifacts/fullscreen/final-verification/viewport/viewport-results.json` 和 `artifacts/fullscreen/production-final/production-transition.json`。浏览器意外错误和失败请求为空；此前 `npm test` 12/12。最终 revision 以包含本页的本地提交为准。

图像为艺术转译，构图接近真实模型但局部轮廓与材质不逐像素相同。少数窗口比例的留白可能出现原图边界；不以模糊、拖尾、遮罩或裁图掩盖。源模型、网页 GLB 和登记相机数据没有本轮修改。
