# 狮相万象 · 构图交接与文化可视化设计

## 当前界面与交接（2026-10-28）

首页显示完整醒狮和六个艺术入口。选择后真实三维相机在整窗飞向部位，随后平滑交接到对应的宽屏艺术图片。图片完成替换后模型隐藏并暂停，GSAP 将完整图片缩小并贴齐左上，导航同步左移。右侧保留空白展示区域，不显示文化标题、页签、图解、文字或数据。模型不拆解、不移动节点；旧文化组件和素材保留在工程中，不作为当前页面使用。

六个部位各有 16:10、16:9、约 1.882:1 与约 2.37:1 四种独立生成图；生成时分别以相同三维终点的对应窗口截图作为构图依据，旧主图仅供材质风格参考。提示、来源、图片尺寸见 `artifacts/fullscreen/IMAGE_PROMPTS.md`，相机登记见 `public/data/handoff-cameras.json`。图像是艺术转译，局部造型和材质与实际模型不同，不是逐像素配准或实测照片。

`frameLayout()` 以所选素材比例计算完整图像的等比 `contain` 区域，`LionWorld.resize()` 以对应的中央 3:2 光圈和 view offset 扩展三维视口；模型的相机位置、目标和 FOV 沿用登记终点。交接时透明模型层位于图片上方，两层同步淡化，减少图片边界对淡出模型的遮挡。当前不使用模糊扩边、拖尾、遮罩或图像裁切。窗口比例不完全匹配时，按用户选择保留少量纯色留白；如果生成图主体正好跨越图像边界，留白与图像的边界可能可见。

窗口尺寸变化时，已解码的新比例图片仅在仍对应当前章节和最新尺寸时切换；图片加载失败时保留已显示图。`epoch` 和可取消的 GSAP 动画处理改选、返回等中断。旧版右侧文化交互、图表及其他静态说明留在下方作为历史记录，不代表当前界面或当前功能验证。

## 当时的体验

首页让用户先面对一头完整醒狮，只保留模型观察和六个部位控件；左上角印章图标已移除。底部六个入口使用独立 image_gen 艺术 PNG。点击后先全屏运镜，再原地交接给这一部位独立生成的主图；模型隐藏并暂停后，GSAP 将完整图片缩放并移到左上角，导航同步左移。图片移动结束，右侧文化阅读区才进入。

原始 `.blend` 不覆盖，三维节点不做局部位移、切割或爆炸。眼部仍与头壳融合；源模型毛发与材质的网页适配见 [MODEL_AUDIT.md](MODEL_AUDIT.md)。

## 固定画幅如何衔接相机与图片

### 光学和版面约束

`frameLayout()` 位于 `src/interaction/layout.mjs`。画幅宽度取 3 的整数倍，高度为对应的 2 倍整数，确保 CSS 子像素舍入不会改变 3:2 比例。World 使用精确的 `aspect = 1.5`，相机 FOV 为 34°。生成图片同为 3:2，DOM 中以 `object-fit: contain` 和居中定位完整显示。

首页和运镜的三维视口覆盖整个窗口；居中的最大完整3:2区域保留主图登记时的相机投影，窗口多出的区域继续显示模型。交接时整窗模型平滑淡出，图片仍以原3:2构图出现。不预留右侧面板或导航高度。图片完全替换模型后，才对图片画幅作 `x / y / scale` 变换，最终左上坐标为 `(0,0)`，保持完整取景。左图目标宽度通常为屏宽62%，并受窗口高度减148px的可用高度限制；右栏从图右加24–48px间距开始，顶72px、底24px，常用桌面占约三分之一宽度。导航中心跟随左图，其宽度不超过900px及左图宽度。

动画驱动归一排版进度而非过期像素终点，窗口变化时重新计算当前位置。三维容器内部尺寸在运镜、淡化和图片位移时不变；`LionWorld.resize()` 使用未缩放布局尺寸，避免隐藏模型在缩放图片期间反复调整画布或返回时缩小两次。

### 镜头终点

`LionWorld.js` 的 `HANDOFF_FRAMINGS` 给六个部位配置方向、基于部位包围盒尺度的目标偏移、观察距离系数。目标点和距离以真实 `PartRegistry` 边界为依据，模型不移动。相机在目标点间插值，并以方向四元数插值和轻微径向弧度绕行，GSAP 用 `power2.inOut` 控制运动节奏。

捕获时的 `position`、`target`、FOV、3:2 画幅和部位边界保存在 `public/data/handoff-cameras.json`，它是本次生成构图的登记记录。运行时实际终点应与该记录核对；若调整 GLB、统一缩放、镜头配置或 FOV，需要重新捕获并生成图片。

### 状态和交接时序

`AtlasExperience` 按如下状态组织流程：

1. **overview**：真实完整模型可旋转、缩放、拾取；无文化栏与章节图片。
2. **travel**：禁用模型交互并清除悬停材质；相机在全屏画幅中飞向部位，画幅和导航不移动。图片读取、解码与必要分析并行准备，文化文字隐藏。
3. **handoff**：确认镜头到达登记终点、图片解码和比例有效后，整窗模型与中央图片平滑交接。重叠期间图片四周渐变羽化，随着模型消失收窄至零；完成后恢复完整图片。返回时同一进度反向运行，不推拉裁图。
4. **arranging**：图片完全显示后，模型层设为 `visibility: hidden`、`opacity: 0`，并执行 `setActive(false)` 取消三维 RAF。随后仅图片画幅与导航作 GSAP 位移/等比缩放，图片贴齐左上；文化栏仍不可见且不可获取焦点。
5. **study**：排版移动结束，右侧文化叙事开始 GSAP 动画，真实模型保持隐藏和暂停。
6. **returning / switching**：先将图片和导航恢复全屏位置，再激活同镜头模型并淡出图片；随后返回原整体视角或开始下一章全屏运镜。

默认相机旅行约2.15秒，原地淡化约1.05秒，图片与导航排版移动约1.15秒。返回/切章先用约0.85秒恢复全屏，再淡回模型；回整体镜头约1.65秒。减少动态效果偏好使用极短时长，保持相同顺序。时长是编辑选择，不是历史节奏或物理量。终点只显示图片与文字，三维资源保留供返回复用。

### 取消、返回和失败恢复

每次用户操作递增 `epoch`，取消旧 GSAP tween 与相机 flight；异步图片和分析只在请求仍有效时推进界面。相机 Promise 对被取消的旅行返回 `{ completed: false }`，避免旧完成回调切回过期章节。

整体镜头只在第一次离开首页时保存。返回动画中再次选择章节不会覆盖它；成功回到整体后才清空保存状态。图片读取失败则取消过期过渡，恢复居中、可操作的完整模型。组件卸载时清理相机 tween、交互事件、RAF、几何、材质、纹理与图像资源。

## 右侧双页签与 GSAP 叙事

`src/content/chapters.js` 提供主图、标题和形态解释；`src/content/culture.js` 提供图解、步骤、背景、方法及来源。`CulturalPanel.jsx` 的内容仅在 `study` 状态变为可见。标题和引言位于上方，下方为可独立滚动的“文化图解 / 形态数据”页签内容，避免长文化内容挤压完整主图。

默认文化页显示艺术图解；数据页显示原始几何分析、图例、方法、构件数量、宽高比、三轴尺度条与样本数量，织锦附带真实纹理色带。切换页签时滚动回到顶部。页签使用 `tablist / tab / tabpanel`、关联标签与活动页签焦点；焦点位于页签时左右方向键切换，`Home / End` 选择首尾，事件不会触发全局章节切换。

GSAP 负责以下实际动画：

- 编号、英文研究标签与分隔线依次出现。
- 中文标题按字符包在独立 span 中，以纵向位移、微旋转、透明度和 stagger 逐字进入。
- 引言与来源等内容依次向上淡入；页签内容切换时整体轻移淡入。
- SVG 实测线条按实际路径长度设置 `strokeDasharray / strokeDashoffset`，由 GSAP 描线。
- 数据页的路径以实际 SVG 路径长度重新描线。

采用 `gsap.context`、时间线与明确清理处理章节切换。文字动画不在相机飞行时提前播放，也不以 CSS 过渡冒充 GSAP。图片与文化文字负责观看节奏，实测小图为叙事提供可复核的形体线索。

## 真实分析：沿用 PartRegistry，扩充数据阅读

`src/content/parts.js` 集中定义 `atlasPart`、源名称后备规则、点击别名、投影平面和分轴方向。复杂网格用 BVH 加速表面拾取。头壳点击可通过 `head` 别名进入眉目章节，但眉饰测量不包含整个头壳。

`PartRegistry.analyze()` 首次进入时计算并缓存。完整 `bounds` 访问所有原生顶点及其世界变换；有限抽样边界另存为 `sampleBounds`，派生毛发不混入原生构件测量。同一源对象的多材质 primitive 按 `sourceName` 合并统计，`objectCount` 与 primitive、draw calls 不是同一口径。

用于轮廓和分箱的顶点最多 7,000 个，为确定性顶点索引抽样；存在顶点密度偏差。宽高比例使用完整包围盒，尺寸采用数字模型比例，不推断未标定的实物毫米数。

| 章节小图 | 实际计算 | 表达边界 |
| --- | --- | --- |
| 眉饰径向包络 | 将眉饰样本投影后划入 48 个角度分箱，绘制最大半径包络 | 不表示已分离眼球、含孔洞轮廓或精确眼眶边缘 |
| 额饰空间关系 | 原始构件中心的固定轴测投影，横向宽度归一化为图形标记 | 连线不是骨架，标记的固定高度不是实物厚度 |
| 垂须宽度 | 沿 `y` 轴的 28 个分箱，间隔抽取部分有效区间显示采样宽度 | 对称铺排用于比较，不声称原网格对称；不是网格切片 |
| 织锦表面坐标 | 从真实主 UV 属性取确定性点样本，按实际边界归一化显示 | 不是完整 UV 岛、纹理拉伸检测或原纹样矢量提取 |
| 云边宽度节律 | 沿 `z` 轴统计分箱宽度，保留原序列并作五点邻域移动平均 | 不是频谱、曲率或真实装饰周期；边缘窗口截短 |
| 口齿构件投影 | 上牙、下牙、舌片中心的正面投影与相对横向宽度 | 包围范围不是牙形精确轮廓，不推断转轴、骨骼或真实开合动画 |

当前界面不再展示旧版双图参数滑块、几何线描模式或空间文字标注。对应的算法和旧组件可以留存复用，但不将未在本版界面呈现的功能描述为当前交互。

新增三轴尺度条使用完整包围盒的 `size`，各条相对当前部件最长轴归一；数值为统一显示尺度下的模型单位，不标成未校准的厘米或毫米。样本数与网格顶点数分别列出，说明采样覆盖范围。

### UV、纹理与色彩口径

织锦章节调用 `analyzeTextureStudy()`，对原生身体网格作最多 2,200 个系统抽样三角面的纹理研究，并缓存结果。主 UV 输出最多 800 点；精简小图再取其中每三个点中的一个。所有点来自实际属性，而不是为了图形密度手工生成。

纹理工具在异步读取前保存原始材质引用，应用相应 UV 通道、贴图矩阵、包裹方式与翻转，读取实际像素；在 linear RGB 中处理基色与可能存在的顶点色，再编码到 sRGB。颜色份额以抽样三角形的世界空间面积估计，不是镜头可见像素百分比。读取失败的有纹理面会排除并记录警告，无纹理时才明确回退为材质基色。

`sampleObjectGeometry()` 的面积统计遍历原生三角形，但其 `materialAreas` 色板只包含材质 baseColor；导出审计中的 `texturePalettes` 则是原纹理图像的像素份额。三者不能互换。当前织锦数据页使用 `analyzeTextureStudy()` 的实际 UV 与纹理面积估计色带，不把生成图片的颜色当作模型测量。

## 信息来源必须区分

| 类型 | 来源 | 可用于说明 | 不用于证明 |
| --- | --- | --- | --- |
| 模型测量 | 原生顶点、对象变换、完整包围盒 | 构件数量、中心、比例 | 实物尺寸、隐藏制作骨架或机械机构 |

## 验证方法与限制

验证按范围分开：

- `npm test`：几何与画幅等现有算法测试。
- `npm run test:browser`（`tests/handoff-browser.mjs`）：全屏交接回归，逐帧采样六章的实际画幅、透明度、相机、模型活动状态与导航位置，核对严格阶段顺序及原登记终点；另验证快速改选、中途返回、窗口变化、节点不变与图片失败恢复。默认写 `artifacts/transition/`。
- `node tests/enrichment-browser.mjs`：新增界面检查，核对六张艺术入口、六张文化图与点击区域、步骤解说滚入阅读区、文化/数据页签及键盘行为、数据图与色带、桌面窗口及十二张独立资产。默认地址 `5175`，用 `ATLAS_URL` 覆盖；用 `ATLAS_EVIDENCE` 指定证据目录。相同脚本可检查生产静态预览，本轮预览端口为 `4175`。
- `npm run build`：生成静态生产文件。既有 `tests/production.mjs` 仍用于主图加载回归，其地址变量为 `ATLAS_PRODUCTION_URL`。
- `node tests/production-transition-browser.mjs`：生产普通动态模式的黑盒验证，不依赖开发诊断对象；直接采样画幅、图片/模型可见性、导航与标题动画。默认访问4175并输出 `artifacts/transition/production/`。

本文件描述当前实现与验证入口，不提前宣称正在运行的检查通过。本轮验证写入 `artifacts/transition/`；`artifacts/handoff/` 和 `artifacts/enrichment/` 保留前轮历史记录，旧截图不代表本轮布局。AI主图与三维参考仍有局部转译差异；同构图交叉淡化提供连续观看体验，不等于逐像素注册或几何修复。
