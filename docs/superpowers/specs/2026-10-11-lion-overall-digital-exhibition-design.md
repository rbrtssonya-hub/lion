# 广府醒狮数字展厅整体页设计规格

## 目标

将现有《南风有狮》整体/结构模型页升级为以醒狮为中心的交互式数字图鉴：中央保留可旋转的 GLB 模型，左右以文化解读和结构工艺信息形成三栏阅读关系，点击热点后联动模型聚焦、引导线和信息面板。

## 已确认约束

- 顶部继续使用现有红金章节导航，模型页当前章节为“整体”，结构页当前章节为“结构”。
- 原始 `lion-overall.glb` 保持不改动；它只有一个合并网格，因此结构拆解只能呈现为准确标注的结构示意和局部信息可视化，不能伪造真实独立零件。
- 动作、神态、评分仍是现有占位章节，本次只改整体/结构模型页。
- 运行资源继续从 `source/public/assets/` 提供，数据、样式和 Three.js 服务按现有 React + Vite 边界维护。
- 桌面端优先适配 1920×1080 和 2560×1440；小屏幕保留可滚动的单列回退。

## 交互设计

1. 页面初始展示完整醒狮，保留拖拽旋转、滚轮缩放和自动旋转。
2. 热点支持悬停高亮、点击选中；选中后调用 Three.js 场景的平滑镜头聚焦，左侧展示文化信息，右侧展示结构、材料和工艺信息。
3. “查看结构”进入结构章节并显示当前热点的结构引导；滑杆只控制示意层显隐强度，并通过文案明确合并网格边界。
4. “重置视角”恢复初始相机与选中状态；“复原结构”从结构章节返回整体章节。
5. 模型载入失败时继续保留海报、信息面板和重试按钮；离开页面时回收 Three.js 监听器、动画帧和 GPU 资源。

## 视觉设计

- 背景从单一暗红改为中央暖米金、两侧朱红/赭红/暖墨棕的层次渐变，叠加低对比云纹、旋眉纹和纸张肌理感 CSS 图案。
- 中央舞台占主体宽度，模型有柔和金色光晕和轻量展示底座；左右面板采用半透明暖纸色/深朱红卡片、细金线和统一编号系统。
- 不使用霓虹、黑色大底、密集装饰或会抢夺模型焦点的科技特效。

## 验收标准

- `/`、`/#/model` 和 `/#/structure` 的导航、模型加载与既有章节行为继续可用。
- 首页式导航和新透明狮头保持不变。
- 页面存在文化面板、结构面板、热点列表、查看结构、重置视角和复原结构入口。
- 点击至少一个热点后，选中状态、文化标题、结构标题和镜头聚焦状态同步变化；点击重置后恢复。
- 结构页保留滑杆，并清楚显示“合并网格 / 结构示意”边界。
- 在 1920×1080、2560×1440 和 390×844 下无横向溢出；模型失败回退仍可操作。
