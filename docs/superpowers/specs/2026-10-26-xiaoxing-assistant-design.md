# 小醒桌宠与醒狮讲解设计

用户于2026-10-26明确要求执行已讨论的分阶段方案，并补充鼠标拖动和符合角色设计的解说声音。当前选择为二次元Q版醒狮服装少女，主视觉严格参照用户附件，保留红白金配色与头身比例。

## 当前阶段与已延期事项

完成可编辑分层源文件、实际活动的眼睛/眉毛/嘴巴、可拖动桌宠、上下文章节对话框、四章可信本地问答、DeepSeek兼容的服务端接口与失败兜底。用户随后明确：DeepSeek API 后面配置，本阶段先完成前面的设计，因此不以真实模型调用冒充验收。语音为清亮亲切、略有元气的年轻女声；优先可离线播放的固定章节讲解，动态答案只能使用符合条件的中文声音，无合适声音则明确保持文字。

## 行为与边界

桌宠以约120px高度固定在电脑视口边角，鼠标拖动须有阈值、指针捕获、边界约束与取消恢复，拖动结束不触发点击。位置安全持久化，窗口变化后重新约束。点击打开非模态面板，支持讲解本页、推荐问题、自由输入、来源入口、收起与Escape。四章变化更新问题与介绍，保留会话。入场影片、设置面板和全屏场景期间避免覆盖关键内容。

角色由对齐透明图层组成，修复后的脸底覆盖移动部件下方；头部/身体、双眼、双眉、闭口/微笑/说话口型独立。提供待机、倾听、思考、回答状态，遵守减少动态、前后台暂停与卸载清理。可编辑源文件与制作提示留在source创作分类，网页只部署运行资产。

问答优先使用现有网站核实过的内容；每条知识包含章节与来源。未知问题说明未收录并给出相关章节。佛鹤狮保持融合形制，结构为资料重建/可见结构示意，八态保持AI辅助视觉与定性观察提示，不宣称情绪识别、测量或评分。

## 网络架构

浏览器向同源 `/api/xiaoxing/chat` 发送问题、当前章节和有限历史。Node处理器检索可信知识、对配置的大模型服务发出受限请求，并仅返回可信来源。未配置、超时、断网、错误或强制离线时返回本地答案。EXE渲染器继续只访问本地，联网由受控Node处理器完成；公开EXE配置自有HTTPS网关，提供商密钥只留在服务端。`--offline`强制本地。
