## 四章职责与页面形式

| 顶栏 | 路由 | 章节职责 | 页面形式 |
| --- | --- | --- | --- |
| 序 | `entry` | 入场与溯源 | 保留电影首屏；进入后保留一屏史册与清楚的章节去向 |
| 造 | `model` | 外形、部位、形制与有依据的制作线索 | 主场景为完整模型；局部页签深入，避免再增长页 |
| 舞 | `action` | 动作观赏与八态观察 | 三维戏台保持高潮；八态入口首屏可见 |
| 传 | `spread` | 所收录案例的地点、生活场景与传播资料 | 地图和当前卡片同屏；简短文字收束 |

四章保持单屏展览与局部阅读，不机械规定每章四个全屏。标题、副文案和交互反馈延续纸白、墨黑、朱红、暖金及既有字体。电影、宣纸、剧场和水墨可保留各自特色，使用共同的章节识别建立联系。

单字章名旁保留可读的辅助说明：序“循狮入境”、造“扎作观形”、舞“观舞传神”、传“狮行远方”。主视觉和已确认入场笔刷字不重绘，不替换运行图片、模型或视频。

## 序章与来源入口

1. 保留当前入场动画、入场短片、首页循环、跳过、重播与音量行为。首页主标题和原“探索更多”书法图保留。
2. 《岭南醒狮志》继续七页，保留现有卷曲、首次翻阅策略、底部时间线、引导角色、图注与来源。传播和传承页承担历史概要，新传章承担具体案例，二者不复制大段正文。
3. 原文化照片不再作为首页独立一级展板；按内容归到造、舞或传的阅读上下文。
4. 形制对照迁入造章后，首页不重复渲染同一组完整对照。
5. 资料与许可始终有明确入口，使用现有 `HomeCultureSources` 的内容与局部阅读能力。它是辅助阅读，退出后回到触发入口；不占用第五个内容章。
6. 史册附近保留造、舞、传的直接入口，不要求按顺序读完书。

## 造章

主场景保留完整模型、六组可观察部位、真实投影标签、点击聚焦、复原、加载与故障阅读回退。当前资产是完整多网格外观模型，并有部分表面语义分区，不描述为可拆解的完整内构。

局部内容使用三个清楚的入口：“观形”“形制”“工艺”。

- 观形：既有模型与部位说明。继续保留眉眼、狮嘴通往指定八态并返回原部位的关系。
- 形制：复用现有佛山、鹤山、佛鹤单狮与对照内容。佛鹤明确为融合形制。静态图不证明真实步法；不新增无来源色卡或六维参数。
- 工艺：以现有有来源的“扎、扑、画、装”线索及广州狮头照片说明制作与外观的关系。清楚说明实景照片未显示内部竹架，不据此推断机关。可用原生 SVG 表示四工序的概念顺序，但不画未经核实的眼部转轴、拉绳、握把或内部机械结构。

模型几何、材质、毛发、HDRI 和原始资产不改；不新增压暗材质、剖切、隐藏、爆炸或重新绑定。

## 舞章与八态

1. 保留当前戏台、四面巨幕、中央醒狮、鼓道具与已有环绕、缩放、切幕、播放器和静音策略。
2. 四段分别为“探青采青／抖毛／狮子吐球／踩梅花桩”，作为四段动作观赏呈现，不改名暗示同一场连续采青。文案沿用现有证据边界。
3. 增加可选的“顺序观赏”：从当前或首幕开始按四段顺序播放，允许停止和单幕回看；末幕结束显示简洁的前往传章入口。该状态必须是主动开启，不改变默认单段循环行为。无法确认媒体连续性时不称“完整套路”。
4. 仅在现有相机 API 能支持的范围内提供真实空间机位，名称为正面、侧面等观看位置。不声称鼓手或狮尾内部视角，不承诺双人配合、鼓谱或动作机制教学。
5. 八态入口在戏台初始界面即可见；`state` 路由继续存在，作为舞章下的独立观察页。进入后顶栏仍高亮舞章，并可返回戏台。
6. 从造章部位进入八态时，继续提供返回原部位；常规返回戏台与上下文返回各有明确文案，不能覆盖原有往返行为。
7. 八态保留当前图、诗性标题、观察解读、滚轮与三组对照。继续标明“AI辅助视觉／定性观察提示／等待真实样本校核”。本版不增加固定鼓型对应。

## 传章与案例数据

地图标注“所收录案例分布示意”，作为已收录照片与说明的空间索引。使用原生 SVG 绘制简化陆地与地点，不加国家边界、方向性航路或迁移先后动画，不表达完整传播史或全球覆盖率。

已具备材料的地点为：

| 地点 | 现有材料 | 阅读重点 |
| --- | --- | --- |
| 广州／佛山 | 广州狮头、佛山桩上照片与现有资料 | 岭南制作与表演，作为阅读起点 |
| 香港 | 九龙公园白狮与狮队实景 | 表演现场与群体配合 |
| 新加坡 | 安祥路锣鼓、春节狮头、ABC社区照片 | 会馆、节庆和社区生活 |
| 旧金山 | 唐人街高台与桩上表演 | 当地表演案例 |
| 埃德蒙顿 | 文化节撒青实景 | 节庆交流与观众互动 |

地点卡片包含名称、原照片、原图注、摄影者、原许可与来源链接，以及不超过两段的现有观察说明。一个地点有多幅照片时允许局部切换。没有澳门、马来西亚、欧洲或澳洲的对应材料就不创建声称已有案例的节点。

地点选择必须支持点击与键盘。减少动态时直接显示选中结果。照片按原比例展示，保留许可及图片故障回退，不把照片背景中的表演者认作人物肖像模块。

收束使用“鼓声未远”及返回戏台／序的入口。关于今天的学习和传承，引用现有史册与资料的概括内容，不新增未经核实的年份、统计、采访或个人模块。

## 明确暂不进入本版的内容

- 固定五处、固定顺序、带判错的点睛游戏及 `lionAwakened` 通关状态。点睛可作为后续艺术互动候选，仪式依据与专用素材成熟后再单独设计。
- 未经核实的狮头内部剖面、拉绳与机关图。
- 新的鼓型—八态对应、完整采青套路教学与双人配合演示。
- 将独立“阿南”鼓点采青／梅花桩游戏接入主站。它们保持在 `source/design/lion-mini-games/`，不扩大前次独立试玩范围。
- 新依赖、新主色、新字体、人物模块、运行媒体替换、手机端专项、离线 EXE 重打包与任何远程发布。

## 架构与行为约束

导航可见章节与合法路由分开维护，`entry/model/action/spread` 为顶栏四章，`state` 为保留的子页。保留 `intro → entry` 与 `structure → model` 旧别名、非法地址回退、浏览器前进后退及 `#state`／`#/state`。

`ChapterIdentity` 能为 `state` 取得舞章序号和子页描述。新 `spread` 需要自己的分发和背景，不落入当前非神态即动作的默认分支。共享导航测量与设置不能因为顶栏文案变短或新路由而出现错位、空高亮或不可用控件。

React 管理选择、弹层与播放编排；Three 服务继续负责场景与资源回收。原生状态和现有 hooks 足够，不新增全局状态库。局部切换应停止不可见视频和图形活动；进入／退出八态的播放器状态需要明确恢复，不出现双音轨。

## 验收

- 路由：四章可直达；八态在舞章高亮；旧链接、前进后退、结构部位往返可用；非法地址回序。
- 内容：七页史册、三形制对照、四段视频、八态与现有许可保留；地图节点和照片地点对应；无未经证实的新工艺或史实。
- 交互：一屏主体完整；资料可访问并可返回；地图键盘可选；顺序观赏主动开启、可停止、末幕可去传章；默认单段循环不变。
- 音画：既有静音与音量偏好有效；切章、八态往返和后台不叠加播放；模型与视频加载失败保留可理解回退。
- 电脑：1366×768、1440×900、1920×1080 检查主要场景，无横向溢出，关键按钮和图注可读，设置打开后仍可用；减少动态可完成主流程。
- 工程：运行 `npm test`、`npm run build`、相关 Chrome 通道 Playwright；保存实际命令与结果及新审查截图，登记新增文件，不重算无关媒体清单。
- 交付：同步 `wiki_memory/`，审查本任务 diff，精确暂存并本地提交；不合并主线，不 push，不发布。
