# 舞章入口与内部场景一致

用户已授权实现，并指出现有海报戏台和卷轴长廊与进入后的实际场景不一致。

1. 入口左窗复用 `createActionTheater`，使用同一房间、完整醒狮、四面屏幕和灯光设置；右窗复用八态 `Scene` 的世界、图片、空间路径和站点坐标。
2. 保留宣纸山水背景和向内对称边框。统一拖动控制实际相机，边框只作轻微响应；右侧视角朝向画面中部。
3. 入口不显示体验页工具栏，使用独立预览视角，不污染八态全局滚动状态；隐藏和退出时停止/回收渲染、媒体及事件。
4. 验证实际资产、相机移动与近远物体投影差异、进入前后内容一致、两条路由、失败回退和原体验页；完成构建、资产与记忆检查，审查后提交推送。

参考项目的分层视差交互继续采用独立实现；不复制没有声明许可证的第三方源码。此前“轻量图片拼景”的实现被本次共享真实场景预览取代。
