# 内容深化与电脑端自适应执行计划

## Spec and Global Constraints

依据：本轮用户批准的《内容深化与全站电脑端自适应优化》五节方案。F盘工程为唯一实施位置；2026-10-20最新指令改为新分支、本地提交、禁止推送和合并main。基线70ac3b6，分支codex/content-responsive-2026-10-20。动作专属组件、样式、媒体与场景完全不动；公共规则须隔离影响。只做电脑端，不新增依赖、图片、评分、持久化设置或EXE。保留视频、原书页引擎、摄影署名、AI边界与公共设置应用范围。

## Architecture and Interfaces

沿用React静态资料、现有底板参数及Hash章节。新增类型/神态对照为组件内临时状态；八态使用稳定ID；App内临时观察请求连接模型与神态并保存返回位置。布局依据可用容器而非screen.width，设置余宽不足900继续覆盖回退。640px比较并排、760px类型左右展开、1000px模型左右；更窄/更矮电脑允许正常纵向阅读。

## Review Focus

对照重复选择交换、退出恢复、焦点和轮播键盘隔离；跨章Hash与浏览器返回不丢模型/滚动状态；推开和缩放不裁切/不隐藏溢出；动作资源字节与行为不变；来源断言有官方证据，未授权照片不发布。

### Task 1: 类型对照与集中资料

Produces: 类型对照界面、稳定来源与精简历史/摄影说明。
Consumes: 现有lionTypes、阅读底板和来源ID。

1. 添加真实浏览器类型对照、重复交换、退出恢复测试；运行应因控件缺失失败。
2. 实现单狮/对照切换，默认佛山/鹤山，保留单狮展开、图片失败回退与作用域键盘；按三个统一维度呈现资料。
3. 精简历史与摄影正文，按历史文化/形制工艺/摄影许可整理来源，核对官方资料；不恢复人物/热点。
4. 运行相关浏览器测试及npm test。Expected:全部通过。

### Task 2: 神态对照与结构关联

Produces: 稳定八态ID、三组对照和App内观察请求。
Consumes: 模型既有部位/相机、ChapterPage的state分支。

1. 添加神态对照与结构往返真实浏览器测试，先运行确认失败。
2. 实现喜乐/惊疑/动静对照及状态/焦点恢复；完善结构说明层次，眉眼到惊、狮嘴到乐仅为观察推荐。
3. 跨章保留Hash格式，回到模型恢复原部位、相机、详情标签与位置；普通导航清除过期上下文。
4. 运行相关浏览器测试及npm test。Expected:全部通过。

### Task 3: 电脑端容器与设置适配

Produces: 目标页面/加载/设置的宽高自适应。
Consumes: Tasks1/2新阅读框、既有公共设置，不新增存储字段。

1. 新增窄余宽/低高度/对照布局的真实尺寸与可达性测试，确认基线失败。
2. 实现640/760/1000px容器布局与低高度纵向阅读；首页对称/透明侧轨/大字保持；模型resize与热点一致。
3. 加载必要文案始终可读；九页设置统一层次与单位；动作CSS/场景不改。
4. 运行矩阵与设置/导航回归。Expected:无横向溢出、遮挡、拉伸或不可达内容。

### Task 4: 全量验证与独立审核

1. 运行npm test、生产构建、相关电脑开发/生产E2E与动作回归；保存真实QA和结果。
2. 覆盖1024x768/1366x768/1440x900/1920x1080/2560x1440/3840x2160/1280x600，125%/150%缩放及280/460/760px设置。
3. 独立审核整支diff，重要问题以失败测试复现再修复；核对动作文件、媒体、依赖和引擎无改动。
