# 舞章对称景窗入口实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按用户确认的山水背景与对称参考图，为三维展厅和醒狮八态制作不同内容、可拖动视角的入口。

**Architecture:** `action` 承载舞章选择页，原四面展厅移至 `theater`，`state` 深链接继续可用。入口采用原生 CSS 三维层、透视与受限镜头，沿用 Mostar 的分层及缓动思路独立改写；不新增依赖，不同时装载两套完整体验。

**Tech Stack:** React / Vite / CSS 3D / Pointer Events / Playwright。

**Spec:** 用户 2026-10-29 实施指令与 `source/design/dance-entrance/reference.png`；原背景 `F:/数媒竞赛/醒狮素材/醒狮模型背景.png`。

## Global Constraints

- 电脑端为目标；左右等宽、向中间对称，右窗朝左，背景采用原图。
- 左窗是暖金环幕戏台；右窗为八态纵深画廊，内容不可重复。
- 交互采用有限角度拖拽、键盘旋转和复位；拖拽不误触进入；减少动态时保留入口。
- 正式标题和按钮使用 DOM 文字。预览中 AI 辅助素材如实说明。
- 仅暂存本任务文件或 hunk，保留已有八态、结构、语音等未提交内容。
- Mostar 未声明开源许可；记录来源及核实时间，交互独立改写，不搬运其代码和素材。

## Review Focus

- 短桌面窗口及设置面板打开时，两个入口仍可见；点击页面先按全站 guard 关闭设置，关闭后入口可点。
- 拖动后点击入口、浏览器前进后退、直接 `#/state` / `#/theater` 可用。
- 图片失败和减少动态时仍有标题、文字入口及清晰状态。
- 退出后清理指针监听、观察器、动画帧，不把重型展厅预加载到入口。
- 当前工作区包含未提交的八态纵深；验收记录区分当前组合树和本次提交范围。
