# 八态三秒五官分层动作扩展

用户已认可惊态三秒动作，并直接要求“其他七个也要按照这样来设计”。在同一隔离分支5f20050上完成全部七态，不以整图缩放代替五官分层，不改变布局和章节转场。

## 设计与接口

八态均采用已有原图分区+隐藏补绘底图，3秒点击短动作并复位。各态独立描出左右眉、左右眼、狮口（以实际可见区域为准），原图静止与失败回退。喜轻扬含笑、怒压眉凝目、哀垂眉敛目收口、乐舒展欢腾、动顾盼起势、静凝目微收、疑一眉挑起试探；惊保持认可版本。以上为AI辅助视觉演绎，不当作真实狮艺采样。

分区数据接口：每态profile为{underpaintKey,parts:[{name,path,origin,delay,peak,relaxed}],foreground:[{cx,cy,r}],foregroundPaths?:[SVG path],timing?:{peak,hold,relax,second,secondHold}}；坐标1254×1254，部件名eye-left/eye-right/jaw/brow-left/brow-right。每部位duration=3000-delay，峰值及回收变换按神态独立设计。共用渲染/取消/解码逻辑，不复制八套组件，不加依赖。
